Unit 2 – Electronic Spreadsheet (Advanced) using LibreOffice Calc

1. Introduction to Multiple Sheets

A spreadsheet workbook can contain more than one worksheet. When the amount of information becomes large, it is often better to divide the information into different sheets instead of keeping everything on one sheet.

Formal Definition:
A multiple-sheet spreadsheet is a workbook containing two or more worksheets that can store, organise and work with related data separately or together.
Simple Definition:
Multiple sheets mean keeping different sets of related information on different sheets inside the same spreadsheet file.

Why Use Multiple Sheets?

  • To organise large amounts of information.
  • To keep related information separately.
  • To make a workbook easier to understand.
  • To avoid putting too much information on one worksheet.
  • To perform calculations using information stored on different sheets.
  • To create a structured workbook.
Example:
A teacher may create separate sheets named January, February, March and April to maintain monthly records.

Other Examples

  • Marks – Attendance – Fees
  • Sales – Expenses – Profit
  • January – February – March
  • Class 9 – Class 10 – Class 11
  • Product List – Customer List – Sales Report

2. Single Sheet vs Multiple Sheets

Single Sheet Multiple Sheets
All information is stored on one worksheet. Information can be divided among several worksheets.
May become difficult to manage when data is large. Large information can be organised into separate sheets.
Suitable for small datasets. Useful for larger or logically divided datasets.
Less sheet navigation is required. Users can move between different sheets.

3. Setting Up Multiple Sheets

LibreOffice Calc allows users to create and manage several sheets inside the same workbook.

Creating a New Sheet

  1. Open LibreOffice Calc.
  2. Open an existing workbook or create a new spreadsheet.
  3. Look at the sheet tabs at the bottom of the window.
  4. Use the option for inserting a new sheet.
  5. A new worksheet will be added.

Renaming a Sheet

  1. Locate the sheet tab.
  2. Right-click the sheet tab.
  3. Select the option to rename the sheet.
  4. Enter a meaningful name.
  5. Confirm the new name.
Use meaningful sheet names such as January Sales, Marks, Attendance or Expenses.

Moving a Sheet

  1. Locate the sheet tab.
  2. Select the sheet.
  3. Use the sheet management option to move it.
  4. Choose its new position.
  5. Confirm the change.

Copying a Sheet

  1. Select the sheet tab.
  2. Open the sheet management options.
  3. Choose the option for moving or copying the sheet.
  4. Select the destination.
  5. Choose the copy option if a separate copy is required.
  6. Confirm the operation.

Deleting a Sheet

  1. Select the sheet that you want to remove.
  2. Right-click the sheet tab.
  3. Select the delete sheet option.
  4. Confirm deletion if prompted.
Deleting a sheet can remove the data stored on that sheet. Always check the sheet name before deleting it.

Changing the Order of Sheets

Sheets can be rearranged so that related sheets appear together.

  1. Select the required sheet tab.
  2. Use the sheet move option or drag the sheet tab when supported.
  3. Place the sheet at the desired position.
  4. Check the new order.

Selecting Multiple Sheets

More than one sheet can be selected when the same operation needs to be performed on multiple sheets.

When multiple sheets are selected, changes made to one selected sheet may also affect the other selected sheets. Always check which sheets are selected before entering or modifying data.

5. References to Other Sheets

Formal Definition:
A reference to another sheet is a cell or range reference that uses data stored on a different worksheet of the same workbook.
Simple Definition:
It means using information from one sheet while working on another sheet.

Why Use References Between Sheets?

  • To combine information from different sheets.
  • To perform calculations using data stored elsewhere.
  • To avoid entering the same information repeatedly.
  • To keep data organised.
  • To create summary reports.

Basic Idea

Suppose a workbook contains:

  • January
  • February
  • March
  • Summary

The Summary sheet can use information from January, February and March.

Example of a Sheet Reference

=January.B2

This represents a reference to cell B2 of the January sheet in Calc's sheet-reference notation.

The exact reference displayed by Calc can depend on how the reference is entered. The safest method for beginners is to create the reference by clicking the required sheet and cell while entering the formula.

6. Practical: Referencing a Cell from Another Sheet

Suppose the January sheet contains a sales value in B2 and we want to display it on the Summary sheet.

Step 1 – Prepare the Sheets

  1. Create two sheets.
  2. Rename them January and Summary.

Step 2 – Enter the Source Value

  1. Open the January sheet.
  2. Click cell B2.
  3. Enter 5000.
  4. Press Enter.

Step 3 – Go to the Summary Sheet

  1. Click the Summary sheet tab.
  2. Select the cell where you want the value to appear.

Step 4 – Start the Formula

  1. Type =.
  2. Click the January sheet tab.
  3. Click cell B2.
  4. Complete the formula.
  5. Press Enter.

The Summary sheet now displays the value from January B2.

Step 5 – Test the Link

  1. Return to the January sheet.
  2. Change the value in B2.
  3. Return to Summary.
  4. Check whether the referenced value changes accordingly.
This demonstrates an important benefit of linking: the summary can obtain the updated value from the source cell instead of requiring the user to enter it again manually.

7. Referencing a Range from Another Sheet

A reference does not have to contain only one cell. A range of cells can also be used in calculations.

Suppose the January sheet contains sales values in B2:B6. A Summary sheet can use that range to calculate a total.

Practical Steps

  1. Open the Summary sheet.
  2. Select the cell where the result is required.
  3. Type a suitable formula, such as a SUM formula.
  4. Move to the January sheet when selecting the range.
  5. Select the required range.
  6. Complete the formula.
  7. Press Enter.
  8. Check the result.
A formula may use the equivalent of:
=SUM(January.B2:B6)

8. References to Other Documents

Formal Definition:
An external reference is a reference that obtains data from another spreadsheet document or external file.
Simple Definition:
It means using data from a different spreadsheet file in the current spreadsheet.

Why Use External References?

  • To use information stored in another workbook.
  • To avoid repeatedly copying the same data.
  • To create reports based on data maintained in another file.
  • To connect related spreadsheet documents.

Example

A school may maintain:

  • Student_Marks.ods
  • Student_Attendance.ods
  • Final_Report.ods

The final report may use information from the other files.

External references create a relationship between documents. If the source file is moved, renamed or deleted, the reference may need attention or may no longer work as expected.

9. Practical: Using Data from Another Spreadsheet Document

Step 1 – Create the Source File

  1. Open LibreOffice Calc.
  2. Enter sample data.
  3. Save the file with a meaningful name.

Step 2 – Create the Destination File

  1. Create another spreadsheet.
  2. Save it separately.

Step 3 – Create the External Reference

  1. Select the cell in the destination document.
  2. Begin entering the required formula/reference.
  3. Open or select the source spreadsheet when required.
  4. Select the required sheet.
  5. Select the required cell or range.
  6. Complete the reference.
  7. Confirm the formula.

Step 4 – Test the Reference

  1. Change the source value.
  2. Save the source document.
  3. Check the destination document.
  4. Verify whether the linked information is updated according to the link settings and document state.
Do not move or rename the source document while learning external references. Keep the source and destination files in known locations.

10. Hyperlinks to a Sheet

Formal Definition:
A hyperlink is a clickable reference that takes the user to another location, such as another sheet, document, webpage or file.
Simple Definition:
A hyperlink is a clickable link that helps you quickly move from one location to another.

Why Use Hyperlinks in a Spreadsheet?

  • To create quick navigation.
  • To connect related sheets.
  • To create a menu or index sheet.
  • To make large workbooks easier to navigate.
A workbook may have a Home sheet containing links to:
  • January
  • February
  • March
  • Summary

11. Practical: Create a Hyperlink to Another Sheet

Step 1 – Prepare the Workbook

  1. Create at least two sheets.
  2. Rename them Home and Marks.

Step 2 – Select the Cell

  1. Open the Home sheet.
  2. Select the cell where the hyperlink should appear.
  3. Enter text such as Open Marks Sheet.

Step 3 – Open Hyperlink Options

  1. Select the cell containing the text.
  2. Open the hyperlink command in LibreOffice.
  3. The hyperlink dialogue will appear.

Step 4 – Choose the Destination

  1. Select the appropriate document/sheet destination option.
  2. Select the current workbook if the target is inside the same workbook.
  3. Choose the required sheet.
  4. Specify the required target cell if needed.

Step 5 – Apply the Hyperlink

  1. Check the displayed target.
  2. Confirm the hyperlink.
  3. Close the hyperlink dialogue.

Step 6 – Test the Hyperlink

  1. Use the hyperlink according to LibreOffice's current hyperlink activation behaviour.
  2. Check whether the Marks sheet opens.
  3. Verify that the correct destination is reached.

12. Editing and Removing Hyperlinks

Editing a Hyperlink

  1. Select the cell containing the hyperlink.
  2. Open the hyperlink editing option.
  3. Change the displayed text or target as required.
  4. Save/apply the changes.
  5. Test the hyperlink again.

Removing a Hyperlink

  1. Select the cell containing the hyperlink.
  2. Use the option for removing the hyperlink or formatting as appropriate.
  3. Check that the hyperlink is no longer active.
Editing changes the destination or hyperlink properties. Removing a hyperlink removes the clickable connection.

13. Relative and Absolute Hyperlinks

Relative Hyperlink:
A relative hyperlink identifies a destination in relation to the location of the current document.
Absolute Hyperlink:
An absolute hyperlink specifies the complete location of the destination.

Simple Understanding

Suppose a file is stored inside a folder and the linked file is also stored in a known location relative to that folder. A relative path can describe the destination based on that relationship.

An absolute path specifies the complete location of the destination.

Comparison

Relative Hyperlink Absolute Hyperlink
Uses a location relative to the current document. Uses the complete destination location.
Can be useful when related files are kept together. Clearly specifies the complete location.
Can be affected if the relative folder structure changes. Can be affected if the complete destination location changes.
When files are moved between computers or folders, hyperlink behaviour may change depending on whether relative or absolute paths were used.

14. Practical: Understanding Relative and Absolute Hyperlinks

Relative Hyperlink – Practical Idea

  1. Create a folder for your spreadsheet project.
  2. Keep the main spreadsheet inside it.
  3. Keep the linked file in the same project folder or a related subfolder.
  4. Create the hyperlink.
  5. Move the complete project folder as a unit when testing portability.
  6. Check whether the hyperlink continues to work.

Absolute Hyperlink – Practical Idea

  1. Create a hyperlink to a file with its complete location.
  2. Save the spreadsheet.
  3. Move or rename the destination file.
  4. Test the hyperlink.
  5. Observe why a changed complete path can cause the link to fail.
Remember:
Relative = location in relation to the current file.
Absolute = complete specified location.

15. Linking External Data

Formal Definition:
Linking external data means establishing a connection between a spreadsheet and information stored outside the current worksheet or document.
Simple Definition:
Instead of making a separate copy of information, the spreadsheet can maintain a connection to the original data source.

Copying vs Linking

Copying Data Linking Data
A separate copy of the information is created. A relationship with the source is maintained.
Changes in the original may not automatically appear in the copied data. The linked data can be updated from the source according to the link mechanism.
Does not necessarily depend on the original source after copying. May depend on the source location or source document.

Why Link External Data?

  • To use information maintained in another source.
  • To reduce repeated data entry.
  • To prepare reports using existing data.
  • To maintain a connection between related information.

16. Practical: Linking External Data

  1. Open LibreOffice Calc.
  2. Create or open the destination spreadsheet.
  3. Identify the external data source.
  4. Select the appropriate method for inserting or linking external data.
  5. Specify the source location when required.
  6. Select the required data.
  7. Confirm the link/import settings.
  8. Insert the linked data.
  9. Check the displayed information.
  10. Save the destination spreadsheet.
  11. Test whether the linked data can be updated when the source changes.
The exact options available can depend on the type of external data source. Always check the source location and connection settings carefully.

17. Linking Registered Data Sources

Data Source:
A data source is a location or system from which information can be obtained for use in an application.
Registered Data Source:
A registered data source is a data source that has been registered with LibreOffice so that LibreOffice applications can identify and use it.
Simple Definition:
A registered data source is a data source that LibreOffice has been told about and can access through its data-source features.

Why Register a Data Source?

  • To make the data source available to LibreOffice.
  • To organise access to external data.
  • To allow LibreOffice applications to work with registered data sources.
  • To use structured external information when required.

Examples of Data Sources

  • Database information.
  • Structured records.
  • Other supported external sources.

18. Practical Understanding: Registered Data Source

  1. Identify the data source that you want LibreOffice to use.
  2. Register the data source using LibreOffice's data-source management facilities when required.
  3. Provide the necessary source information.
  4. Save the registration.
  5. Open the LibreOffice application that will use the source.
  6. Access the registered data source.
  7. Select the required data.
  8. Use the data for the required spreadsheet task.
  9. Check that the correct source and records are being used.
Different types of data sources may require different connection and registration settings. Do not change database or connection settings without understanding the source.

19. Linking Data vs Copying Data

Basis Copying Linking
Relationship Creates a separate copy. Maintains a connection with the source.
Updates Usually requires manual updating. Can obtain updated information from the source according to the link.
Dependency Less dependent on the original source after copying. May depend on the source location.
Use Useful when an independent copy is required. Useful when the source data may change and the relationship should be maintained.

20. Hyperlink vs Data Link

Hyperlink Data Link
Primarily used for navigation. Primarily used to obtain or reference data.
Takes the user to another location. Connects information between sources or sheets.
Example: Click a cell to open the Summary sheet. Example: Use a value from another sheet in a calculation.

21. Common Practical Mistakes

  1. Wrong sheet selected: Always check the sheet tab before entering or referencing data.
  2. Incorrect cell reference: Check the row and column carefully.
  3. Incorrect sheet name: Use the exact sheet name when creating references.
  4. Renaming a sheet without checking references: Always verify formulas and links after major sheet changes.
  5. Broken external link: Check whether the source file was moved, renamed or deleted.
  6. Wrong hyperlink target: Test every hyperlink after creating it.
  7. Relative/absolute path confusion: Understand which type of path is being used.
  8. Deleting a source: Do not delete a source file that is required by an external reference.
  9. Not updating linked information: Check the source and link settings when the expected data does not appear.
  10. Accidentally selecting multiple sheets: Check the sheet tabs before making changes.

22. Important Questions

1. What is a multiple-sheet workbook?

A multiple-sheet workbook is a spreadsheet file containing two or more worksheets that can store and organise related information.

2. Why are multiple sheets useful?

Multiple sheets help organise large amounts of information into separate but related worksheets and make a workbook easier to manage.

3. What is a reference to another sheet?

It is a reference that uses information stored in a different worksheet of the same workbook.

4. What is an external reference?

An external reference obtains data from another spreadsheet document or external file.

5. What is a hyperlink?

A hyperlink is a clickable reference that takes the user to another location such as another sheet, document, file or webpage.

6. What is a relative hyperlink?

A relative hyperlink identifies a destination in relation to the location of the current document.

7. What is an absolute hyperlink?

An absolute hyperlink specifies the complete location of the destination.

8. Differentiate between relative and absolute hyperlinks.

A relative hyperlink uses a destination relative to the current document, whereas an absolute hyperlink specifies the complete destination location.

9. What is external data?

External data is information obtained from outside the current worksheet or spreadsheet document.

10. What is a registered data source?

A registered data source is a data source that has been registered with LibreOffice so that it can be identified and used by LibreOffice applications.

11. Differentiate between copying and linking data.

Copying creates a separate copy of information, while linking maintains a connection with the original source so that source information can be obtained or updated through the link.

23. Application-Based Questions

Case 1 – Monthly Sales Workbook

A shop owner wants to maintain separate records for January, February and March but also wants a summary of all three months.

View Answer

The owner can create separate sheets for January, February and March and use a Summary sheet to reference or calculate information from those sheets.

Case 2 – School Marks Report

A teacher stores student marks on a sheet named Marks and wants the value of a particular cell to appear automatically on a Summary sheet.

View Answer

A reference to the required cell on the Marks sheet can be created in the Summary sheet. If the source value changes, the referenced result can reflect the updated source value.

Case 3 – Navigation Sheet

A workbook contains ten different sheets. The user wants one Home sheet from which other sheets can be opened quickly.

View Answer

Hyperlinks can be created on the Home sheet to provide quick navigation to the different worksheets.

Case 4 – Source File Moved

A spreadsheet contains a reference to another spreadsheet file. The source file is later moved to another folder and the linked information is no longer available as expected.

View Answer

The external reference may depend on the source file's location. The source path or link should be checked and corrected if necessary.

Case 5 – Relative vs Absolute

A student is preparing a project folder containing several related spreadsheet files and wants to move the complete folder to another computer.

View Answer

Relative hyperlinks can be useful when related files maintain the same folder relationship. The complete project structure should be kept together and tested after moving it.
