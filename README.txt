EDUSPHERE WITH SATYAM - FREE WEBSITE STARTER

Files:
- index.html : main website
- style.css  : design and responsive layout
- script.js  : menu and sample MCQ interactions

HOW TO CUSTOMISE:
1. Open index.html in a browser to preview the website.
2. Replace sample text with your real educational content.
3. Replace sample links (#) with Google Drive/PDF/PPT/article links.
4. Replace the sample email address in index.html.
5. You can upload these files to a free static hosting service.

IMPORTANT:
This is a starter website. No paid domain or hosting is required for the files themselves.
