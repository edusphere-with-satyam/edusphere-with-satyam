SESSION 1: CREATE AND APPLY STYLES IN THE DOCUMENT

Class 10 Information Technology – Code 402 | Unit 1: Digital Documentation (Advanced)

LibreOffice Writer Digital Documentation Class 10 IT 402

📘 Session Introduction

Styles are one of the most useful features of LibreOffice Writer. They help us apply the same formatting to different parts of a document quickly and consistently.

Instead of manually changing font, size, colour, alignment and spacing again and again, we can create or apply a style. When the style is changed, all the text using that style can be updated accordingly.

Exam Point: Styles help in maintaining consistency, saving time and creating professional-looking documents.

🎯 Learning Objectives

After completing this session, students should be able to:

  • Understand the meaning and importance of styles.
  • Identify different categories of styles.
  • Open and use the Styles and Formatting window.
  • Apply styles to text and paragraphs.
  • Use Fill Format to apply styles quickly.
  • Create a new style from a selection.
  • Update an existing style from a selection.
  • Load styles from another document or template.
  • Create a style using drag-and-drop.

1️⃣ What is a Style?

Formal Definition:
A style is a predefined or user-defined collection of formatting properties that can be applied to text, paragraphs, pages, lists, tables or other elements of a document.
Simple Definition:
A style is a ready-made set of formatting instructions that allows us to format a document quickly and consistently.

Example

Suppose all main headings in a document should be blue, bold and 18-point in size. Instead of applying these settings manually to every heading, we can create and apply one heading style.

❓ Question: What is a style in LibreOffice Writer?
🔹 View Answer
A style is a collection of formatting properties that can be applied to document elements such as paragraphs, characters, pages, lists and tables.

2️⃣ Why are Styles Useful?

Styles are useful because they:

  • Save time while formatting a document.
  • Maintain consistency throughout the document.
  • Make documents look professional.
  • Allow multiple formatting properties to be applied together.
  • Make it easier to modify formatting later.
  • Help create structured documents.
  • Are useful when creating a Table of Contents.
Remember: If the same formatting has to be used repeatedly, using a style is generally better than formatting each item manually.
❓ Question: Mention any three advantages of using styles.
🔹 View Answer
Three advantages are:
  1. They save formatting time.
  2. They maintain consistency in the document.
  3. They make future formatting changes easier.

3️⃣ Categories of Styles

LibreOffice Writer provides different categories of styles for different purposes.

  • Paragraph Styles
  • Character Styles
  • Frame Styles
  • Page Styles
  • List Styles
  • Table Styles
Exam Point: Remember the six major categories: Paragraph, Character, Frame, Page, List and Table.
❓ Question: Name the different categories of styles in LibreOffice Writer.
🔹 View Answer
The major categories are Paragraph, Character, Frame, Page, List and Table styles.

4️⃣ Paragraph Style

Formal Definition:
A paragraph style is a collection of formatting properties that can be applied to an entire paragraph.
Simple Definition:
It controls the appearance and layout of a complete paragraph.

It may control properties such as:

  • Font and font size
  • Alignment
  • Indentation
  • Line spacing
  • Spacing above and below paragraphs
  • Borders and background
❓ Question: What is a paragraph style?
🔹 View Answer
A paragraph style is a collection of formatting properties that can be applied to an entire paragraph.

5️⃣ Character Style

Formal Definition:
A character style is a collection of formatting properties applied to selected characters or words within a paragraph.
Simple Definition:
It changes the appearance of selected letters, words or characters without changing the entire paragraph.

Character styles may control:

  • Font
  • Font size
  • Font colour
  • Bold or italic appearance
  • Character effects
❓ Question: What is a character style?
🔹 View Answer
A character style is used to apply formatting to selected characters or words within a paragraph.

6️⃣ Frame Style

Definition:
Frame styles are used to control the formatting and positioning of frames and objects in a document.

Frames can be used for objects such as images, text boxes and other document elements.

❓ Question: What is the purpose of a frame style?
🔹 View Answer
Frame styles are used to control the formatting, positioning and appearance of frames and objects in a document.

7️⃣ Page Style

Definition:
A page style is a collection of formatting settings that controls the layout and appearance of a page.

It can include settings such as:

  • Page size
  • Margins
  • Orientation
  • Headers and footers
  • Columns
❓ Question: What is a page style?
🔹 View Answer
A page style is a collection of settings used to control the layout and appearance of a page, such as margins, orientation, page size and headers or footers.

8️⃣ List Style

Definition:
A list style is used to control the appearance and formatting of numbered or bulleted lists.

It helps maintain a consistent appearance for lists throughout a document.

❓ Question: What is a list style used for?
🔹 View Answer
A list style is used to control the formatting and appearance of numbered and bulleted lists.

9️⃣ Table Style

Definition:
A table style is used to apply a consistent set of formatting properties to tables.

It can help maintain consistent borders, backgrounds, alignment and other table formatting.

❓ Question: What is a table style?
🔹 View Answer
A table style is a set of formatting properties used to give tables a consistent appearance.

🔟 Styles and Formatting Window

Definition:
The Styles and Formatting window is a tool in LibreOffice Writer that allows users to view, manage, create, modify and apply styles.
Simple Explanation:
It acts like a central place from where we can manage the styles used in our document.

Opening the Styles Panel

In LibreOffice Writer, the Styles panel can generally be opened through the Styles menu or the corresponding keyboard shortcut/interface control, depending on the LibreOffice version.

The exact appearance or menu location may vary slightly between LibreOffice versions.
❓ Question: What is the purpose of the Styles and Formatting window?
🔹 View Answer
It is used to view, manage, create, modify and apply styles in a document.

1️⃣1️⃣ Applying a Style

Applying a style means selecting a suitable style and assigning it to the required text, paragraph or other document element.

Practical Steps

Step 1: Open the document in LibreOffice Writer.
Step 2: Select the text or place the cursor in the required paragraph.
Step 3: Open the Styles panel.
Step 4: Select the appropriate style category.
Step 5: Select the required style.
Step 6: The selected content will receive the formatting defined by the style.
❓ Question: What is meant by applying a style?
🔹 View Answer
Applying a style means assigning a predefined or user-created set of formatting properties to the required document element.

1️⃣2️⃣ Fill Format

Definition:
Fill Format is a feature that allows a selected style to be applied repeatedly to different parts of a document.

Practical Steps

Step 1: Open the Styles panel.
Step 2: Select the required style.
Step 3: Activate the Fill Format mode.
Step 4: Click the paragraphs or document elements where the style should be applied.
Step 5: Exit Fill Format mode after completing the task.
Use: Fill Format is useful when the same style needs to be applied to several different places quickly.
❓ Question: What is Fill Format used for?
🔹 View Answer
Fill Format is used to apply the selected style repeatedly to different parts of a document quickly.

1️⃣3️⃣ Creating a New Style from a Selection

Definition:
A new style can be created from a formatted selection so that the same formatting can be reused elsewhere in the document.

Practical Steps

Step 1: Format a piece of text or paragraph according to your requirement.
Step 2: Select the formatted content.
Step 3: Open the Styles panel.
Step 4: Use the option for creating a new style from the current selection.
Step 5: Give the new style a meaningful name.
Step 6: Save/create the style.
❓ Question: Why can a style be created from a selection?
🔹 View Answer
It allows the formatting of an existing selection to be converted into a reusable style.

1️⃣4️⃣ Updating a Style from a Selection

An existing style can be modified by changing the formatting of selected content and then updating the style.

Practical Steps

Step 1: Apply the existing style to some content.
Step 2: Modify the formatting of the selected content.
Step 3: Open the Styles panel.
Step 4: Select the option to update the style from the current selection.
Step 5: The style is updated with the new formatting.
❓ Question: What happens when a style is updated from a selection?
🔹 View Answer
The formatting of the selected content is used to update the existing style, so the style contains the new formatting.

1️⃣5️⃣ Loading Styles from Another Document or Template

Definition:
Loading styles means importing styles from another document or template so that they can be used in the current document.

Practical Steps

Step 1: Open the document in which the styles are required.
Step 2: Open the Styles panel.
Step 3: Choose the option for loading/importing styles.
Step 4: Select the source document or template.
Step 5: Select the required style categories/options.
Step 6: Import the styles.
❓ Question: What is meant by loading styles?
🔹 View Answer
Loading styles means importing styles from another document or template so that they can be used in the current document.

1️⃣6️⃣ Creating a New Style Using Drag-and-Drop

LibreOffice Writer can also provide a convenient way to create a new style by dragging formatted content into the Styles panel.

General Practical Procedure

Step 1: Format the text or paragraph as required.
Step 2: Select the formatted content.
Step 3: Open the appropriate Styles category.
Step 4: Drag the selected content to the Styles panel as supported by the LibreOffice interface.
Step 5: Provide a suitable name for the new style.
Step 6: Save the style.
❓ Question: How can a new style be created using drag-and-drop?
🔹 View Answer
A new style can be created by selecting suitably formatted content and dragging it to the appropriate Styles area, followed by naming and saving the new style.

💻 Full Practical Activity: Create and Apply Styles

Perform the following activity in LibreOffice Writer.

Task

Create a document on the topic “Importance of Information Technology”. Create and apply different styles to the title, headings and body paragraphs.

Suggested Procedure

Step 1: Open LibreOffice Writer.
Step 2: Type a title: Importance of Information Technology.
Step 3: Apply a suitable heading/title style to the title.
Step 4: Type two or three paragraphs about Information Technology.
Step 5: Apply a suitable paragraph style to the body paragraphs.
Step 6: Create a new style from a formatted selection.
Step 7: Apply the newly created style to another part of the document.
Step 8: Modify the formatting and update the style from the selection.
Step 9: Save the document.
Learning Outcome: You should be able to create, apply and modify styles instead of formatting every part of the document manually.

⭐ Advantages of Using Styles

  1. Styles save time.
  2. They provide consistency.
  3. They make documents professional.
  4. They make formatting easier to modify.
  5. They help organise long documents.
  6. They are useful for creating structured documents.
  7. They reduce repetitive manual formatting.
❓ Question: Why are styles preferred over repeated manual formatting?
🔹 View Answer
Styles are preferred because they save time, maintain consistency and allow formatting to be changed easily across multiple parts of a document.

🧠 Application-Based Questions

Q1. A student has a 20-page document with 15 headings. All headings need the same formatting. What should the student use?
🔹 View Answer
The student should use a heading style so that the same formatting can be applied consistently to all headings.
Q2. A student manually formats every heading separately. What problem can this create?
🔹 View Answer
Manual formatting can take more time and may result in inconsistent formatting throughout the document.
Q3. A student wants to change the formatting of all content using the same style. What is the benefit of using a style?
🔹 View Answer
The student can modify the style, allowing the formatting associated with that style to be changed consistently.
Q4. A particular paragraph has been formatted exactly as required. The student wants to reuse the same formatting. What can be done?
🔹 View Answer
The student can create a new style from the formatted selection and apply that style elsewhere.
