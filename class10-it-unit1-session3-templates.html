SESSION 3: CREATE AND USE TEMPLATE

Class 10 Information Technology (402) | Unit 1 – Digital Documentation (Advanced)

📘 Session Introduction

A document often contains a fixed structure, design, formatting and other elements that need to be used repeatedly. Creating the same structure again and again can waste time and may also result in inconsistent formatting.

LibreOffice Writer provides Templates to solve this problem. A template stores a predefined document structure and formatting that can be reused to create new documents.

In simple words: A template is a ready-made document design that can be reused whenever a similar type of document is required.

📄 What is a Template?

Formal Definition:
A template is a pre-designed document that contains predefined formatting, styles, layout, text, images and other document elements that can be reused to create new documents.
Simple Definition:
A template is a ready-made pattern or model of a document that can be used again and again.

Examples of Templates

  • School notice template
  • Letter template
  • Resume template
  • Report template
  • Certificate template
  • Business letter template
  • Meeting agenda template
  • Invoice template
Important: A template is not simply an ordinary document. It is designed especially for repeated use.

🔄 Template vs. Normal Document

Normal Document: A normal document is generally created for a particular purpose and contains the actual information that will be used or shared.
Template: A template contains a predefined structure and design that can be reused to create multiple similar documents.
Example: Suppose a school regularly creates notices. Instead of designing the heading, school name, logo, font and layout every time, a notice template can be created once and reused.
Remember: Template = Reusable design/structure
Document = Actual document containing specific information

🧩 Elements That Can Be Included in a Template

A template may contain many predefined elements, such as:

  • Page size and page orientation
  • Margins
  • Fonts and font sizes
  • Paragraph formatting
  • Heading styles
  • Page styles
  • Headers and footers
  • Tables
  • Images and logos
  • Bulleted and numbered lists
  • Predefined text
  • Colours and other formatting
  • Page numbering
The purpose of these elements is to make future documents consistent and faster to prepare.

⭐ Advantages of Using Templates

  1. Saves Time: Repeated formatting does not have to be done again.
  2. Consistency: Similar documents can have the same design and formatting.
  3. Reduces Repetitive Work: Common elements only need to be created once.
  4. Improves Appearance: Documents can have a professional and organized appearance.
  5. Easy Reuse: The same structure can be used whenever required.
  6. Reduces Formatting Errors: Predefined formatting reduces the possibility of inconsistent formatting.
  7. Improves Productivity: More documents can be created in less time.

🛠️ Creating a Template from an Existing Document

If you have already prepared a document and want to reuse its design and formatting, you can save it as a template.

Step-by-Step Procedure

Step 1: Open LibreOffice Writer.
Step 2: Open the document that you want to use as the basis for your template.
Step 3: Check the document carefully.
Step 4: Make sure that the required formatting, headings, logo, tables, page layout and other elements are correctly arranged.
Step 5: Click the File menu from the menu bar.
Step 6: Select Templates.
Step 7: Select Save as Template.
Step 8: A dialog box for saving the template will appear.
Step 9: Enter a suitable name for the template.
Example: School Notice Template
Step 10: Select an appropriate template category.
Step 11: If required, select the option to make the template the default template for the relevant document type.
Step 12: Click Save.
Step 13: The document is now stored as a reusable template.
Practical Tip: Give templates meaningful names so that they can easily be identified later.

📑 Creating a New Document from a Template

After creating a template, you can use it whenever you need to create a new document with the same structure and formatting.

Step-by-Step Procedure

Step 1: Open LibreOffice Writer.
Step 2: Click File.
Step 3: Select New.
Step 4: Select Templates.
Step 5: The Template dialog will open.
Step 6: Select the category containing your template.
Step 7: Locate the required template.
Step 8: Click the template to select it.
Step 9: Click Open or double-click the template, depending on the LibreOffice version.
Step 10: A new document will be created using the template.
Step 11: Enter the new or required information.
Step 12: Check the document.
Step 13: Save the new document using an appropriate file name.
Important: When you create a new document from a template, you normally work on the new document rather than directly changing the template.

🗂️ Managing Templates

LibreOffice allows users to manage stored templates. Templates can be opened, edited, deleted, moved, exported and organized.

Opening the Template Manager

Step 1: Open LibreOffice Writer.
Step 2: Open the File menu.
Step 3: Select Templates.
Step 4: Select Manage Templates if it is shown in your LibreOffice version.

Common Template Management Operations

Use: Open a template and create a new document from it.
Edit: Modify the template when its design or structure needs to be changed.
Delete: Remove an unnecessary template.
Move: Organize a template into another suitable category or location.
Export: Save a template so that it can be transferred or shared.

✏️ Modifying or Editing a Template

A template may need to be modified when the school name, logo, design, formatting or other standard information changes.

Step-by-Step Procedure

Step 1: Open the Template Manager.
Step 2: Locate the template that you want to modify.
Step 3: Select the required template.
Step 4: Use the available edit option for the selected template.
Step 5: The template will open for editing.
Step 6: Make the required changes.
Step 7: Check fonts, headings, spacing, images, tables, page layout and other elements.
Step 8: Save the changes.
Step 9: Close the template.
The changes made to the template can be used when new documents are created from the updated template.

⚙️ Setting a Default Template

Definition: A default template is a template that LibreOffice automatically uses as the starting point when creating a new document of the corresponding type.

Step-by-Step Procedure

Step 1: Open the Template Manager.
Step 2: Locate the template that you want to make the default.
Step 3: Select the template.
Step 4: Open the template's context menu or available options.
Step 5: Select Set as Default.
Step 6: The selected template becomes the default template.
Step 7: Create a new Writer document to check whether the default template is being used.
Note: The exact wording or location of a command may vary slightly between LibreOffice versions.

🔄 Resetting the Default Template

If you no longer want a custom template to be the default, LibreOffice provides an option to restore the standard default template.

Step 1: Open the Template Manager.
Step 2: Open the options/context menu for the current default template.
Step 3: Select the option to reset or restore the default template.
Step 4: Confirm the operation if LibreOffice asks for confirmation.

🧪 Practical Activity: Create a School Notice Template

In this activity, you will create a reusable template for preparing school notices.

Part A – Prepare the Document

Step 1: Open LibreOffice Writer.
Step 2: Create a new blank Writer document.
Step 3: Type the school name at the top.
Step 4: Select the school name.
Step 5: Apply suitable formatting such as bold, larger font size and centre alignment.
Step 6: Type NOTICE below the school name.
Step 7: Format the word NOTICE appropriately.
Step 8: Add placeholders or suitable spaces for:
  • Date
  • Notice subject/title
  • Main notice content
  • Name of issuing authority
  • Designation
Step 9: Arrange the content properly.
Step 10: Check alignment, spacing and font formatting.

Part B – Save as Template

Step 11: Click File.
Step 12: Select Templates.
Step 13: Select Save as Template.
Step 14: Enter the template name: School Notice Template
Step 15: Select an appropriate category.
Step 16: Click Save.

Part C – Use the Template

Step 17: Open the Template Manager.
Step 18: Find School Notice Template.
Step 19: Select the template.
Step 20: Open the template to create a new document.
Step 21: Enter actual notice information.
Step 22: Check the completed notice.
Step 23: Save the notice with a different file name.
Result: You have created a reusable school notice template and used it to prepare a new notice.

🧠 Application-Based Questions

1. A school prepares 20 notices every month. Each notice has the same school name, logo, heading and basic layout. What should the school use?
▶ View Answer
The school should create and use a template. It will save time and maintain the same formatting in all notices.
2. Ravi created a notice template. He now wants to prepare a new notice without changing the original template. What should he do?
▶ View Answer
Ravi should create a new document from the template. He should enter the new information in the newly created document.
3. A school changes its logo and wants the new logo to appear in future notices created from its template. What should be done?
▶ View Answer
The school should modify/edit the template and replace the old logo with the new logo. The updated template can then be used for new notices.
4. Why is using a template better than designing every similar document from the beginning?
▶ View Answer
A template saves time, reduces repetitive formatting work, improves consistency and helps maintain a professional document structure.

🎯 Important Questions

1. Define a template.
▶ View Answer
A template is a pre-designed document containing predefined formatting, layout, styles and other elements that can be reused to create new documents.
2. Write any four advantages of using templates.
▶ View Answer
Four advantages are:
  1. It saves time.
  2. It maintains consistency.
  3. It reduces repetitive formatting work.
  4. It improves the appearance of documents.
3. How can an existing document be saved as a template?
▶ View Answer
Open the required document, select File → Templates → Save as Template, enter a template name, choose a suitable category and save the template.
4. How can a new document be created from a template?
▶ View Answer
Open LibreOffice Writer, go to File → New → Templates, select the required template and open it. A new document will be created using the template's structure and formatting.
5. What is a default template?
▶ View Answer
A default template is the template automatically used by LibreOffice as the starting point when a new document of the corresponding type is created.
6. Why is template management important?
▶ View Answer
Template management helps users organize, use, edit, delete, move and maintain their templates efficiently.
7. Differentiate between a template and a normal document.
▶ View Answer
A normal document is generally created for a specific purpose and contains actual information. A template is a reusable document structure containing predefined formatting and other elements for creating similar documents.
8. Give two examples where templates can be useful.
▶ View Answer
Templates can be useful for creating repeated documents such as school notices, resumes, letters, reports and certificates.
