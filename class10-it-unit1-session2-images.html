🖼️ SESSION 2: INSERT AND USE IMAGES

Class 10 Information Technology | Subject Code 402

Digital Documentation (Advanced) – LibreOffice Writer

SESSION 2

📘 Session Introduction

Images make a document more attractive, informative and easier to understand. LibreOffice Writer provides several options for inserting and formatting images in a document.

In this session, you will learn how to insert images and control their size, position, alignment, wrapping, anchoring and other properties.

🎯 Learning Objectives

  • Understand the importance of images in a document.
  • Insert an image into a Writer document.
  • Resize and position an image.
  • Align an image properly.
  • Apply suitable text-wrapping options.
  • Understand and use image anchoring.
  • Arrange images and other objects.
  • Crop an image.
  • Modify image properties.
  • Move and delete images.
  • Create an illustrated document using images.

🌟 Importance of Images in a Document

Definition: Images are visual elements such as photographs, illustrations, diagrams or graphics that are inserted into a document to present information visually.

Images can make information easier to understand and can improve the overall appearance of a document. They are especially useful in educational documents, reports, projects, brochures and presentations.

💡 Example – Use of Images

Suppose a student is preparing a document on Computer Education. A suitable computer-related image can be inserted to support the written information and make the document more interesting.

🖼️ Inserting an Image

Definition: Inserting an image means adding a picture or graphic file into a document so that it becomes part of the document content.

LibreOffice Writer allows you to insert an image stored on your computer into the document.

🛠️ Practical Steps – Insert an Image
  1. Open LibreOffice Writer.
  2. Open the document in which you want to insert the image.
  3. Place the cursor at the required location.
  4. Open the Insert menu.
  5. Select the option for inserting an image.
  6. Browse to the folder where the image is stored.
  7. Select the required image file.
  8. Click Open.
  9. The selected image will appear in the document.

📏 Resizing an Image

Definition: Resizing an image means changing its height and width to make it suitable for the document layout.

An image may be too large or too small after insertion. Resizing helps you make the image suitable for the available space.

🛠️ Practical Steps – Resize an Image
  1. Select the image by clicking it.
  2. Selection handles will appear around the image.
  3. Move the pointer to a corner handle.
  4. Drag the corner handle inward to make the image smaller.
  5. Drag it outward to make the image larger.
  6. Adjust the image until it reaches a suitable size.
  7. Prefer using a corner handle so that the image proportions are maintained.
Tip: Avoid stretching an image unnecessarily because it may make the picture look distorted.

📍 Positioning an Image

Definition: Positioning an image means placing the image at the required location on the page in relation to the text and other objects.

The position of an image affects the overall layout of the document. An image should be placed where it supports the related content.

🛠️ Practical Steps – Position an Image
  1. Select the image.
  2. Click and hold the image.
  3. Drag the image towards the required location.
  4. Release the mouse button when the image reaches the desired position.
  5. Check whether the surrounding text is properly arranged.
  6. Make small adjustments if necessary.

↔️ Aligning an Image

Definition: Image alignment refers to placing an image appropriately with respect to the page, paragraph or surrounding content.

Proper alignment gives a document a neat and organised appearance. Depending on the layout, an image may be positioned towards the left, centre or right.

🛠️ Practical Steps – Align an Image
  1. Select the image.
  2. Open the available alignment options.
  3. Choose the required alignment.
  4. Observe the position of the image in relation to the surrounding content.
  5. Adjust the position if the layout does not look suitable.

📝 Text Wrapping

Definition: Text wrapping determines how the surrounding text flows around or beside an image.

Text wrapping is important when an image is placed inside or beside a paragraph. It controls the relationship between the image and nearby text.

🛠️ Practical Steps – Apply Text Wrapping
  1. Select the image.
  2. Open the image's wrapping options.
  3. Review the available text-wrapping choices.
  4. Select a suitable wrapping option.
  5. Observe how the text moves around the image.
  6. Choose the option that produces the required document layout.
💡 Example – Text Wrapping

If a picture is placed beside a paragraph, a suitable wrapping option can allow the paragraph text to flow around the image instead of leaving a large empty area.

⚓ Anchoring

Definition: Anchoring determines how an image or other object is attached or positioned in relation to the document, paragraph, character or page.

Anchoring controls how an image behaves when the surrounding text or document layout changes.

🛠️ Practical Steps – Set Image Anchor
  1. Select the image.
  2. Open the image anchoring options.
  3. Review the available anchoring choices.
  4. Select the appropriate anchor according to the required layout.
  5. Change some surrounding text and observe the behaviour of the image.
  6. Select the anchoring method that gives the desired result.
💡 Example – Anchoring

An image may be anchored to a paragraph so that it remains associated with that paragraph when the text moves. Another anchoring method can associate the image with the page or a particular character.

🔄 Arranging Images

Definition: Arranging an image means controlling its order or position in relation to other objects when multiple objects overlap.

When several images or objects overlap, arranging options can determine which object appears in front and which appears behind another object.

🛠️ Practical Steps – Arrange an Image
  1. Select the image or object.
  2. Open the arranging options.
  3. Choose the required arrangement such as bringing an object forward or sending it backward.
  4. Observe the position of the selected object relative to other objects.
  5. Repeat the process if necessary to obtain the required order.

✂️ Cropping

Definition: Cropping is the process of removing unwanted portions from the visible area of an image without necessarily deleting the original image file.

Cropping is useful when an image contains unnecessary portions that are not required in the document.

🛠️ Practical Steps – Crop an Image
  1. Select the image.
  2. Open the image editing or cropping options.
  3. Select the crop option.
  4. Adjust the crop handles around the image.
  5. Keep only the required portion of the image.
  6. Confirm the crop.
  7. Check whether the final image contains only the required area.

⚙️ Image Properties

Definition: Image properties are the settings used to control different characteristics of an image, such as its size, position, border, spacing and other formatting options.

Image properties allow you to make detailed adjustments to an inserted image.

🛠️ Practical Steps – Modify Image Properties
  1. Select the image.
  2. Open the image properties or formatting options.
  3. Review the available settings.
  4. Adjust the size or position if required.
  5. Set suitable spacing between the image and surrounding content.
  6. Apply a suitable border if required.
  7. Check the wrapping and anchoring settings.
  8. Apply the changes.
  9. Observe the final appearance of the image.

↔️ Moving an Image

Definition: Moving an image means changing its location from one position to another within the document.

An image can be moved when its original position does not fit the document layout.

🛠️ Practical Steps – Move an Image
  1. Select the image.
  2. Place the pointer over the image.
  3. Click and hold the mouse button.
  4. Drag the image towards the required position.
  5. Release the mouse button.
  6. Check the surrounding text and overall layout.

🗑️ Deleting an Image

Definition: Deleting an image means removing the selected image from the document.

An image that is no longer required can be removed from the document.

🛠️ Practical Steps – Delete an Image
  1. Click the image to select it.
  2. Make sure the correct image is selected.
  3. Press the Delete key.
  4. The selected image will be removed from the document.
  5. Check the document layout after deletion.

💻 Practical Activity

Create an Illustrated Document

Create a one-page document on the topic: “Importance of Computers in Education”.

The purpose of this activity is to practise the complete process of inserting and formatting an image in a Writer document.

🛠️ Step 1 – Open LibreOffice Writer
  1. Start LibreOffice.
  2. Select Writer.
  3. Open a new blank document.
🛠️ Step 2 – Create the Document Content
  1. Type the heading: Importance of Computers in Education.
  2. Write a short paragraph explaining the importance of computers in education.
  3. Make sure the heading and paragraph are clearly visible.
  4. Leave suitable space for inserting an image.
🛠️ Step 3 – Insert an Image
  1. Place the cursor at the required location.
  2. Open the image insertion option.
  3. Browse to the location of the required image.
  4. Select a suitable image related to computers or education.
  5. Insert the image into the document.
🛠️ Step 4 – Resize the Image
  1. Select the inserted image.
  2. Use a corner handle to resize it.
  3. Make the image large enough to be clearly visible.
  4. Do not make it unnecessarily large.
  5. Ensure that the image does not look stretched or distorted.
🛠️ Step 5 – Move and Position the Image
  1. Select the image.
  2. Drag it towards the required position.
  3. Place it near the related paragraph.
  4. Check that the image does not unnecessarily cover the text.
  5. Adjust its position if required.
🛠️ Step 6 – Align the Image
  1. Select the image.
  2. Use the appropriate alignment option.
  3. Choose left, centre or right alignment according to the layout.
  4. Check whether the document looks balanced and organised.
🛠️ Step 7 – Apply Text Wrapping
  1. Select the image.
  2. Open the text-wrapping options.
  3. Choose a suitable wrapping method.
  4. Observe how the paragraph text moves around the image.
  5. Choose the wrapping option that gives the neatest layout.
🛠️ Step 8 – Set the Image Anchor
  1. Select the image.
  2. Open the anchoring options.
  3. Choose a suitable anchor.
  4. Make a small change to the surrounding text.
  5. Observe how the image behaves.
  6. Keep the anchoring option that is suitable for the document.
🛠️ Step 9 – Arrange the Image
  1. Select the image.
  2. If another object overlaps the image, open the arrange options.
  3. Bring the image forward or send it backward as required.
  4. Check the order of overlapping objects.
🛠️ Step 10 – Crop the Image
  1. Select the image.
  2. Open the cropping option.
  3. Adjust the crop handles.
  4. Remove unnecessary portions of the image.
  5. Confirm the crop.
  6. Check the final appearance.
🛠️ Step 11 – Modify Image Properties and Border
  1. Select the image.
  2. Open the image properties or formatting options.
  3. Check the image size and position.
  4. Adjust the spacing around the image if required.
  5. Apply a suitable border to the image.
  6. Check the wrapping and anchoring settings.
  7. Apply the changes.
🛠️ Step 12 – Check the Final Appearance
  1. Check whether the image is in the correct location.
  2. Check whether the image size is appropriate.
  3. Make sure the image is not unnecessarily stretched.
  4. Check the text wrapping.
  5. Check the anchoring.
  6. Check the alignment and spacing.
  7. Make sure the image and text create a neat layout.
🛠️ Step 13 – Save the Document
  1. Open the File menu or use the Save command.
  2. Choose the required file name.
  3. Save the document in the desired location.
  4. Make sure the document has been saved successfully.

Suggested file name: Importance_of_Computers_in_Education

  • ✔ Image has been inserted successfully.
  • ✔ Image is in the correct location.
  • ✔ Image size is appropriate.
  • ✔ Image is not unnecessarily stretched.
  • ✔ Suitable text wrapping has been applied.
  • ✔ Suitable anchoring has been applied.

🧠 Application-Based Questions

1. Rahul inserted a large image into his document, but it is covering most of the text. What should he do?

▶ View Answer

He should resize the image and apply a suitable text-wrapping option. He should also check its position and alignment.

2. An image moves unexpectedly when the paragraph is edited. Which image setting should be checked?

▶ View Answer

The anchoring setting should be checked because anchoring determines how the image is attached to the document content.

3. A student wants to remove an unwanted portion from an image. Which feature should be used?

▶ View Answer

The student should use the Crop option.

4. Two images are overlapping and one image needs to appear in front of the other. Which feature can help?

▶ View Answer

The Arrange options can be used to bring an image forward or send it backward.

⭐ Important Questions

1. What is the importance of images in a document?

▶ View Answer

Images provide visual information, improve the appearance of a document and can make complex information easier to understand.

2. What is image resizing?

▶ View Answer

Image resizing means changing the height and width of an image to make it suitable for the document.

3. What is text wrapping?

▶ View Answer

Text wrapping determines how text flows around or beside an image.

4. What is anchoring?

▶ View Answer

Anchoring determines how an image is attached or positioned in relation to the document, paragraph, character or page.

5. What is cropping?

▶ View Answer

Cropping is the process of removing unwanted visible portions of an image.

6. What is the purpose of arranging an image?

▶ View Answer

Arranging controls the order of an image or object in relation to other overlapping objects.

7. How can an image be deleted from a document?

▶ View Answer

Select the image and press the Delete key.
