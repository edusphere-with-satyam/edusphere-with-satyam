🖼️ SESSION 2: INSERT AND USE IMAGES

Class 10 Information Technology (402) | Digital Documentation – Advanced

📘 Session Introduction

A digital document can contain not only text but also graphical elements such as images. Images are useful for making a document more attractive, informative and easier to understand.

LibreOffice Writer provides several options for inserting and working with images. After inserting an image, we can change its size, position, alignment, wrapping and other properties according to the requirements of the document.

Formal Definition:
An image is a graphical object inserted into a digital document to visually represent, explain or support the information presented in it.
Simple Definition:
An image is a picture added to a document to make its content clearer and more attractive.

🎯 Learning Objectives

After completing this session, students will be able to:

  • Understand the importance of images in digital documents.
  • Insert an image into a Writer document.
  • Resize an image while maintaining its proper appearance.
  • Position and align an image.
  • Understand and apply text wrapping.
  • Understand anchoring of images.
  • Arrange images and other objects.
  • Crop an image.
  • Modify basic image properties.
  • Remove an unwanted image from a document.

🌟 Importance of Images in a Document

Images can communicate information visually and can support the text written in a document. A suitable image can make a document easier to read and understand.

Uses of Images

  • Making documents visually attractive.
  • Explaining information with visual examples.
  • Supporting written content.
  • Presenting project work effectively.
  • Creating reports, brochures and posters.
  • Helping readers understand information quickly.
Question: Why are images used in digital documents?
View Answer
Images are used to make documents attractive, support written information and help readers understand the content more easily.

📥 Inserting an Image

Formal Definition:
Inserting an image is the process of adding a graphical file to a document at a required location.
Simple Definition:
Inserting an image means adding a picture to your document.

Steps to Insert an Image

Step 1: Open the required document in LibreOffice Writer.
Step 2: Place the cursor at the location where you want to insert the image.
Step 3: Open the Insert menu.
Step 4: Select the option for inserting an image.
Step 5: Browse to the location where the image is stored.
Step 6: Select the required image.
Step 7: Click Open.
Tip: Use an image that is relevant to the subject of the document.
Question: Where should the cursor be placed before inserting an image?
View Answer
The cursor should be placed at the location where the image needs to be inserted.

📐 Resizing an Image

Formal Definition:
Resizing is the process of changing the width and height of an image according to the requirements of a document.
Simple Definition:
Resizing means making an image larger or smaller.

Steps to Resize an Image

  1. Select the image by clicking on it.
  2. Selection handles will appear around the image.
  3. Drag an appropriate handle to change the size.
  4. Release the mouse button when the desired size is achieved.
Important: The image should be resized carefully so that its appearance does not become distorted.
Question: What is resizing an image?
View Answer
Resizing is the process of changing the width and height of an image according to the requirements of the document.

📍 Positioning an Image

Formal Definition:
Positioning an image means placing it at a specific location in the document according to the required layout.
Simple Definition:
Positioning means deciding where an image should appear on the page.

Common Positions

  • Left side
  • Centre
  • Right side
  • Above the text
  • Below the text
  • Alongside the text
Question: What is meant by positioning an image?
View Answer
Positioning an image means placing it at the required location in a document.

↔️ Aligning an Image

Alignment determines how an image is positioned horizontally in relation to the available space or surrounding content.

Common Alignment Options

  • Left: Places the image towards the left side.
  • Centre: Places the image in the centre.
  • Right: Places the image towards the right side.
Tip: Select an alignment that makes the document look organised and balanced.
Question: Why is proper alignment important for an image?
View Answer
Proper alignment helps maintain a neat, organised and professional appearance of the document.

📝 Text Wrapping

Formal Definition:
Text wrapping is the arrangement of text around an image or other object inserted into a document.
Simple Definition:
Text wrapping decides how text will appear around a picture.

Common Text Wrapping Options

  • None: Text does not flow around the image.
  • Before: Text is positioned before the image according to the selected arrangement.
  • After: Text is positioned after the image according to the selected arrangement.
  • Parallel: Text flows around the image.
  • Through: Text can flow through the area occupied by the image depending on the settings.
  • Optimal: Writer automatically attempts to place the text appropriately around the image.
  • As Character: The image behaves like a character within the text.

Changing Text Wrapping

  1. Select the image.
  2. Open the image wrapping options.
  3. Select the required wrapping style.
  4. Observe the change in the surrounding text.
Question: What is text wrapping?
View Answer
Text wrapping determines how text is arranged around an image or other object in a document.
Question: Which wrapping option makes an image behave like a character?
View Answer
The As Character wrapping option makes the image behave like a character within the text.

⚓ Anchoring an Image

Formal Definition:
Anchoring defines the reference point to which an image or other object is attached within a document.
Simple Definition:
Anchoring tells Writer what part of the document an image is connected to.

Common Anchor Options

  • To Page: The image is associated with a page.
  • To Paragraph: The image is associated with a paragraph.
  • To Character: The image is associated with a character.
  • As Character: The image behaves like a character in the text.
Remember:
Anchoring determines what the image is attached to, while text wrapping determines how text behaves around the image.
Question: What is anchoring?
View Answer
Anchoring defines the reference point to which an image is attached within a document.

🔄 Arranging Images

When two or more images or objects overlap, their order can be changed. Arrange options are used to control which object appears in front of or behind another object.

Important Arrangement Options

  • Bring to Front: Moves the selected object to the front.
  • Send to Back: Moves the selected object behind other objects.
  • Bring Forward: Moves the object one level forward.
  • Send Backward: Moves the object one level backward.
Question: Which option is used to move an object to the front of other overlapping objects?
View Answer
The Bring to Front option is used to move the selected object to the front.

✂️ Cropping an Image

Formal Definition:
Cropping is the process of removing unwanted portions of an image while retaining the required part.
Simple Definition:
Cropping means cutting away unwanted parts of a picture.

Uses of Cropping

  • Removing unwanted portions of an image.
  • Focusing on an important part of the image.
  • Making the image fit better into the document.
  • Improving the overall presentation.

Basic Steps

  1. Select the image.
  2. Choose the cropping option.
  3. Adjust the crop handles.
  4. Keep the required portion of the image.
  5. Apply the crop.
Question: What is cropping?
View Answer
Cropping is the process of removing unwanted portions of an image while retaining the required part.

⚙️ Image Properties

Image properties allow us to control different aspects of an inserted image. These settings help us create a well-organised document.

Important Image Properties

  • Size
  • Position
  • Wrapping
  • Anchoring
  • Alignment
  • Border
  • Spacing around the image
  • Cropping
Question: Name any four properties that can be modified for an image.
View Answer
Any four are: size, position, wrapping, anchoring, alignment, border and cropping.

↔️ Moving an Image

An inserted image can be moved to another location in the document. Its movement can depend on its anchoring and positioning settings.

Basic Steps

  1. Select the image.
  2. Click and hold the image.
  3. Drag it towards the required location.
  4. Release the mouse button.
Important: If an image does not move as expected, check its anchoring, positioning and wrapping settings.
Question: Which settings can affect the movement of an image?
View Answer
The anchoring, positioning and wrapping settings can affect the movement of an image.

🗑️ Deleting an Image

If an inserted image is no longer required, it can be removed from the document.

Steps to Delete an Image

  1. Select the image.
  2. Press the Delete key.
Question: How can an unwanted image be removed from a Writer document?
View Answer
Select the unwanted image and press the Delete key.

💻 Practical Activity

Create an Illustrated Document

Create a one-page document on the topic: “Importance of Computers in Education”.

Instructions

  1. Open LibreOffice Writer.
  2. Type the heading: Importance of Computers in Education.
  3. Write a short paragraph explaining the importance of computers in education.
  4. Insert a suitable image related to computers or education.
  5. Resize the image appropriately.
  6. Position the image properly on the page.
  7. Apply a suitable text-wrapping option.
  8. Experiment with the anchoring option.
  9. Apply a suitable border to the image.
  10. Crop the image if unnecessary portions are present.
  11. Save the document with an appropriate file name.
Learning Tip: Do not focus only on inserting the image. Practise its size, position, alignment, wrapping, anchoring and other properties.

🧠 Application-Based Questions

Q1. Aman inserted a very large image into his project and it occupies almost the entire page. What should he do?
View Answer
He should resize the image so that it fits properly within the available space.
Q2. A student wants text to appear around an image instead of leaving unnecessary blank space. Which feature should be used?
View Answer
The student should use an appropriate text-wrapping option.
Q3. Two images are overlapping and one image needs to appear above the other. Which feature should be used?
View Answer
The Arrange options, such as Bring to Front or Bring Forward, can be used.
Q4. A photograph contains unnecessary portions around its edges. Which feature should be used?
View Answer
The Crop feature should be used to remove unwanted portions.

Bring to Front moves the selected object in front of other overlapping objects.
