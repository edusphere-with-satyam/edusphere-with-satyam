SESSION 5: IMPLEMENT MAIL MERGE

Class 10 Information Technology (402) | Unit 1 – Digital Documentation (Advanced)

📧 Introduction to Mail Merge

Mail Merge is an important feature of LibreOffice Writer that allows us to create multiple personalized documents from one main document and a data source.

For example, a school may need to send the same notice to 100 students. Instead of typing the notice 100 times, we can create one main notice and use Mail Merge to automatically insert each student's name, class, roll number, address, or other information.

Formal Definition:

Mail Merge is a feature of a word processor that combines a main document with a data source containing records and fields to create multiple personalized documents.

Simple Definition:

Mail Merge means creating many similar documents at once by combining one common document with a list of different people's information.

Example: A school wants to prepare certificates for 50 students. The certificate design can remain the same, while the student's name and other details change automatically using Mail Merge.

📌 Why is Mail Merge Used?

Mail Merge is useful when the same type of document has to be prepared for many people, but some information in each document is different.

  • Sending personalized letters to many people.
  • Preparing student notices.
  • Creating certificates with different student names.
  • Preparing invitations.
  • Creating address labels.
  • Preparing envelopes.
  • Generating personalized office documents.
Remember: The main content generally remains the same, while selected information such as name, address or roll number changes for each record.

📚 Important Terms Used in Mail Merge

1. Main Document

Formal Definition: The document containing the common text, formatting and placeholders that will be combined with the data source.
Simple Meaning: It is the common document that will be sent to everyone.

2. Data Source

Formal Definition: A data source is a collection of records containing the information that is inserted into the main document during Mail Merge.
Simple Meaning: It is the list containing information such as names, addresses, roll numbers, etc.

3. Field

Formal Definition: A field represents a particular category of information in the data source, such as Name, Address or Roll Number.
Simple Meaning: A field is a column or type of information.

4. Record

Formal Definition: A record is a complete set of related information belonging to one person or one entry in the data source.
Simple Meaning: One complete row of information is called a record.

5. Merge Field

Formal Definition: A merge field is a placeholder in the main document that is replaced by corresponding information from the data source.
Simple Meaning: It is a place in the document where information from the data list will appear.

🧩 Components of Mail Merge

A Mail Merge process mainly involves:

  1. Main Document – contains common content.
  2. Data Source – contains information about recipients.
  3. Fields – identify different types of information.
  4. Records – contain complete information for each recipient.
  5. Merge Fields – connect the main document with the data source.
  6. Final Merged Documents – personalized documents produced after merging.

🏫 School Example of Mail Merge

Suppose a school has the following data:

Fields: Name | Roll No. | Class | Section
Record 1: Rahul | 12 | 10 | A
Record 2: Priya | 18 | 10 | A
Record 3: Aman | 25 | 10 | B

The main notice can contain merge fields such as Name, Roll No., and Class.

When Mail Merge is performed, Writer creates a personalized version of the notice for each record.

📝 Creating the Main Document

The first important part of Mail Merge is preparing the main document. It contains the common information that will appear in all merged documents.

Practical Steps

Step 1: Open LibreOffice Writer.
Step 2: Create a new Writer document.
Step 3: Type the common content of your letter, notice or document.
Step 4: Apply suitable formatting.
Step 5: Leave appropriate positions for information that will change for different recipients.
Step 6: Save the document with a suitable name.
Example: For a student notice, the common text may include the school name, notice heading and general instructions. The student's name and other individual details can be inserted as fields.

🗂️ Creating the Data Source

The data source contains the information that will be inserted into the main document.

A data source can contain fields such as:

  • Name
  • Roll Number
  • Class
  • Section
  • Address
  • Phone Number
Important: The fields should be named clearly because these names are used while selecting information for the Mail Merge document.

🧙 Using the Mail Merge Wizard

LibreOffice provides a Mail Merge Wizard to guide the user through the Mail Merge process. It can be opened from:

Tools → Mail Merge Wizard

The wizard guides the user through different stages such as selecting the starting document, choosing the document type, specifying recipients, creating salutations, adjusting the layout and completing the merge.

⚙️ Complete Mail Merge Procedure

Part A – Start Mail Merge Wizard

Step 1: Open the main document in LibreOffice Writer.
Step 2: Click the Tools menu.
Step 3: Select Mail Merge Wizard.
Step 4: The Mail Merge Wizard opens.

Part B – Select Starting Document

Step 5: Choose the document that will be used as the starting document.
Step 6: You can use the current document, create a new document, use an existing document, use a template, or use a recently saved starting document.
Step 7: Click Next.

Part C – Select Document Type

Step 8: Select the appropriate document type.
Step 9: For a normal personalized letter, choose the appropriate letter option.
Step 10: Click Next.

Part D – Select Recipients / Data Source

Step 11: Select the address list or data source.
Step 12: If required, create a new address list.
Step 13: Enter the required information into the fields.
Step 14: Add records for different recipients.
Step 15: Save the address list/data source.
Step 16: Select the required data source.
Step 17: Click Next.

Part E – Address Block / Merge Information

Step 18: Select the required fields for the recipient information.
Step 19: Arrange the fields according to the required format.
Step 20: Check the preview of the information.
Step 21: Make corrections if the information is not arranged properly.
Step 22: Click Next.

Part F – Create Salutation

Step 23: Select whether a salutation is required.
Step 24: Select an appropriate greeting if required.
Step 25: Check the preview.
Step 26: Click Next.

Part G – Adjust Layout

Step 27: Check the position of address information and other elements.
Step 28: Adjust the layout if necessary.
Step 29: Click Next.

Part H – Preview

Step 30: Preview the merged information.
Step 31: Move through the records to check different recipients.
Step 32: Check spelling, names, addresses and other information carefully.
Step 33: Correct the main document or data source if required.

Part I – Complete the Merge

Step 34: Proceed to the final step of the Mail Merge Wizard.
Step 35: Choose the required output option.
Step 36: Select the records that should be processed.
Step 37: Choose whether the merged documents should be printed or saved.
Step 38: If saving to a file, select the required saving option.
Step 39: Select the required location and file format where applicable.
Step 40: Complete the Mail Merge operation.
Exam Point: Mail Merge can produce one merged document containing all records or, depending on the output options, individual documents for each record.

🔗 Inserting and Using Merge Fields

Merge fields act as placeholders in the main document. During the merge, they are replaced by corresponding information from the data source.

Example

Main Document:

Dear Name,

You are requested to attend the meeting of Class Class on the scheduled date.
After merging:

Dear Rahul,

You are requested to attend the meeting of Class 10 on the scheduled date.
The same main document can therefore be used for many recipients.

👀 Previewing the Merged Documents

Previewing is important because it allows the user to check how information from different records will appear in the final documents.

  • Check recipient names.
  • Check addresses.
  • Check spelling.
  • Check field placement.
  • Check formatting.
  • Check that no field is missing.
Do not skip preview: An incorrect field, missing record or wrongly arranged address can affect many merged documents.

✏️ Editing Individual Merged Documents

After creating the merged output, it may sometimes be necessary to make changes to an individual document.

Step 1: Complete the merge or create the merged output.
Step 2: Open the merged document.
Step 3: Locate the particular recipient's document.
Step 4: Make the required individual correction.
Step 5: Save the corrected document.
Individual editing is useful when one recipient's document needs a special correction that should not be applied to every record.

🖨️ Printing the Merged Letters

Mail Merge can be used to print personalized letters for multiple records. LibreOffice provides options for selecting the records that should be processed.

Step 1: Complete the Mail Merge.
Step 2: Select the required records.
Step 3: Choose the printer/output option.
Step 4: Check the printing settings.
Step 5: Start printing.

💾 Saving the Merged Output

The merged result can also be saved instead of being directly printed. LibreOffice provides options for saving the output as a file.

Save as Single Document: Creates one document containing the merged data from all processed records.
Save as Individual Documents: Creates a separate document for each processed record.
Remember: The choice depends on the purpose of the work. A single document may be useful for keeping all merged letters together, while individual documents may be useful when each recipient needs a separate file.

🏷️ Mail Merge for Labels and Envelopes

Mail Merge is not limited to ordinary letters. It can also be useful for creating personalized labels and envelopes.

Labels

Labels can contain recipient information such as name and address. The same label format can be used for many recipients.

Envelopes

Recipient information can be combined with an envelope layout so that different envelopes can be prepared using records from the data source.

⚠️ Common Mistakes in Mail Merge

1. What happens if the data source is not selected correctly?
View Answer

The required recipient information may not appear correctly in the merged document. The correct data source should be selected before completing the merge.

2. What happens if the wrong field is inserted?
View Answer

Incorrect information may appear in the final document. The field should match the required information in the data source.

3. Why should the merged documents be previewed?
View Answer

Previewing helps identify incorrect names, missing information, wrong field placement and formatting problems before printing or saving.

4. What is a common problem with the data source?
View Answer

Incomplete or incorrectly entered records can result in incorrect information in the merged documents.

🧪 Practical Activity

Prepare Personalized Student Notices Using Mail Merge

Create a notice for three students using Mail Merge. The notice should contain the student's name, roll number and class.

Procedure

Step 1: Open LibreOffice Writer.
Step 2: Create a new document.
Step 3: Type the school name.
Step 4: Type the heading of the notice.
Step 5: Type the common notice text.
Step 6: Decide where the student's information will appear.
Step 7: Start the Mail Merge Wizard.
Step 8: Select the current document as the starting document.
Step 9: Select the appropriate document type.
Step 10: Create/select the required data source.
Step 11: Create fields such as Name, Roll Number and Class.
Step 12: Enter the first student's information.
Step 13: Enter the second student's information.
Step 14: Enter the third student's information.
Step 15: Save the data source.
Step 16: Insert the required merge fields into the notice.
Step 17: Preview the records.
Step 18: Check all three students' information.
Step 19: Correct any error if found.
Step 20: Complete the merge.
Step 21: Save the merged output.
Step 22: Open the output and verify the personalized notices.
Expected Result: Three personalized notices should be produced from one main notice and three student records.

💡 Application-Based Questions

Question 1: A school wants to send the same invitation to 200 parents, but each invitation must contain a different parent's name. Which feature should be used?
View Answer

The school should use Mail Merge. One main invitation can be combined with a data source containing the parents' names.

Question 2: A teacher has a list of 50 students containing their names and roll numbers. She wants to create individual certificates using one certificate design. What should she use?
View Answer

She should use Mail Merge. The certificate design can be the main document and student information can be stored in the data source.

Question 3: Why is a data source necessary in Mail Merge?
View Answer

The data source stores the changing information for different recipients. Mail Merge uses this information to personalize the main document.

Question 4: A student created a main document but all merged documents contain the same person's name. What should the student check?
View Answer

The student should check the data source, records and merge field selection, and ensure that the correct records are being processed during the merge.
