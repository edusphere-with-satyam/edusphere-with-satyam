Introduction to Reports and Database Management

A database stores information in an organised manner. However, storing information is not enough. We often need to present the stored information in a clear, organised and printable format.

In LibreOffice Base, a Report is used to present information from a database in a properly arranged format. Reports are especially useful when information has to be viewed, shared, printed or presented to others.

Academic Definition:
A report is a database object that presents selected information from one or more database sources in a structured and formatted layout suitable for viewing or printing.
Simple Definition:
A report is a well-organised presentation of database information that makes the data easy to read, understand and print.
Example:
Suppose the Students table contains the names, classes, sections and marks of students. A report can present this information as a properly formatted student marks report.

Purpose and Importance of Reports

A report converts database information into a meaningful and organised presentation. It can arrange information using headings, grouping, sorting and suitable formatting.

Why Are Reports Needed?

  • To present database information clearly.
  • To organise information in a readable format.
  • To group related records.
  • To sort information according to requirements.
  • To prepare information for printing.
  • To create professional-looking documents from database data.
  • To make large amounts of information easier to understand.
  • To provide a formatted view of database information.
Example:
A school can create a report containing student names, classes, sections and marks. The report can be sorted by student name or grouped according to class.

Important Parts of a Report

A report may contain different elements depending on the purpose for which it is created.

Title

The title identifies what the report is about.

Example: Student Marks Report

Field Names

Field names identify the type of information displayed in the report.

Example: Student ID, Name, Class, Section and Marks.

Records

Records contain the actual information displayed in the report.

Grouping

Grouping arranges records according to a common field or category.

Example: Students can be grouped according to Class.

Sorting

Sorting arranges records in a particular order, such as ascending or descending order.

Example: Student names can be arranged alphabetically.

Report Layout

Layout controls how information is positioned and displayed in the report.

Report Wizard

Definition:
Report Wizard is a guided tool in LibreOffice Base that helps users create a report by selecting fields, grouping and sorting data, choosing a layout and completing the report creation process.
In simple words:
Report Wizard guides the user step by step while creating a report.

It is useful for beginners because the user does not have to design the complete report manually from the beginning.

What Can Be Selected Using the Report Wizard?

  • Database table or query as the data source.
  • Fields to be displayed.
  • Field labels.
  • Grouping options.
  • Sorting options.
  • Report layout.
  • Orientation.
  • Report title.
🛠️ Practical Steps – Opening the Report Wizard
  1. Open LibreOffice Base.
  2. Open your database file.
  3. Wait for the main Base window to appear.
  4. Look at the database objects listed on the left side.
  5. Click Reports.
  6. Look for the option to create a report using the wizard.
  7. Click Use Wizard to Create Report.
  8. The Report Wizard window will open.

Selecting Fields for a Report

A database table may contain many fields, but every report does not require every field. The user should select only the fields that are relevant to the purpose of the report.

Field Selection:
Field selection means choosing the required fields from a table or query to be displayed in a report.
Example:
For a student marks report, Student_ID, Name, Class, Section and Marks may be selected.
🛠️ Practical Steps – Selecting and Arranging Fields
  1. Open the Report Wizard.
  2. Select the required table or query.
  3. Look at the available fields.
  4. Identify the fields required in the report.
  5. Select the first required field.
  6. Add or move the field into the selected-fields area.
  7. Repeat the process for every required field.
  8. Check the selected fields carefully.
  9. Remove any field that is not required.
  10. Arrange the fields in a logical order if the wizard provides the option.
  11. Continue to the next stage of the wizard.

Grouping Data in a Report

Definition:
Grouping is the process of arranging records together according to the value of a selected field.
Simple Meaning:
Grouping puts similar records together.
Example:
If the report is grouped by Class, students belonging to the same class can appear together.

Why Is Grouping Useful?

  • It organises related records.
  • It makes large reports easier to read.
  • It separates different categories.
  • It helps users understand relationships among records.
🛠️ Practical Steps – Grouping Students by Class
  1. Continue from the Report Wizard after selecting the fields.
  2. Move to the grouping stage.
  3. Look for the available fields for grouping.
  4. Select the Class field.
  5. Add Class as a grouping field.
  6. Check the grouping order.
  7. Make sure the grouping field is correct.
  8. Continue to the next stage of the wizard.

Sorting Report Data

Definition:
Sorting is the process of arranging records according to a selected field in ascending or descending order.

Ascending Order

Ascending order generally arranges text alphabetically from A to Z and numbers from smaller to larger values.

Descending Order

Descending order generally arranges text alphabetically from Z to A and numbers from larger to smaller values.

Example:
If students are sorted by Name in ascending order, Aman may appear before Neha and Riya.
🛠️ Practical Steps – Sorting the Report by Student Name
  1. Continue in the Report Wizard.
  2. Move to the sorting stage.
  3. Look for the available fields.
  4. Select the Name field.
  5. Set the sorting order to Ascending.
  6. Check that Name is selected as the sorting field.
  7. Review the sorting settings.
  8. Continue to the next stage.
🛠️ Practical Steps – Sorting Marks from Highest to Lowest
  1. Open the Report Wizard.
  2. Reach the sorting stage.
  3. Select the Marks field.
  4. Select Descending order.
  5. Check that the sorting field is Marks.
  6. Check that descending order has been selected.
  7. Continue with the report creation process.

Report Layout and Formatting

Report layout determines how information is arranged on the page. A suitable layout makes the report easier to read.

Important Layout Considerations

  • Page orientation.
  • Arrangement of fields.
  • Report title.
  • Field labels.
  • Spacing between information.
  • Page size.
  • Alignment of information.
  • Overall readability.

Portrait Orientation

Portrait orientation displays the page vertically. It is useful when the report contains fewer columns.

Landscape Orientation

Landscape orientation displays the page horizontally. It can be useful when the report contains many columns.

🛠️ Practical Steps – Selecting Report Layout
  1. Continue in the Report Wizard.
  2. Move to the layout selection stage.
  3. Look at the available layout options.
  4. Select a layout suitable for the number of fields.
  5. Check whether the information is displayed clearly.
  6. Select the appropriate page orientation if available.
  7. Use portrait orientation for a narrow report when suitable.
  8. Use landscape orientation when many columns need to be displayed.
  9. Continue to the next stage of the wizard.

Printing a Report

Reports are often created for printing. Before printing, the user should check the report carefully.

Possible Changes

Report Data Source

Definition:
A data source is the table or query from which a report obtains the information that it displays.

A report does not normally store a completely separate copy of the database information simply for presentation. It uses a database source to obtain the information that it presents.

Example:
The Students table can act as the data source for a Student Marks Report.

Table as a Data Source

A table can be used when the report requires information directly from stored records.

Query as a Data Source

A query can be used when only selected records or selected fields are required in the report.

Example:
A query can select students whose marks are greater than 80. A report can then present only those selected students.

Creating a Report from a Query

A query can filter or select the information required for a report. This is useful when the report should not display every record in the table.

Example:
Suppose we want a report containing only students who scored more than 80 marks. A query can first select those students, and the report can use the query as its data source.
🛠️ Practical Steps – Using a Query as Report Source
  1. Open the database.
  2. Make sure the required query already exists.
  3. Open the Reports section.
  4. Select Use Wizard to Create Report.
  5. Open the source selection option.
  6. Choose the required query instead of the table.
  7. Check the fields available from the query.
  8. Select the fields required for the report.
  9. Continue with grouping if required.
  10. Continue with sorting if required.
  11. Select the required layout.
  12. Enter a suitable report title.
  13. Finish the report creation process.
  14. Open the report.
  15. Check that only the records selected by the query are displayed.

Tables, Queries, Forms and Reports

The four major database objects work together. Understanding their different purposes is essential for working with a database.

Database Object Main Purpose Example
Table Stores data in fields and records. Students table
Query Searches, filters or retrieves required data. Students with Marks > 80
Form Provides a user-friendly interface for entering and viewing data. Student Data Entry Form
Report Presents database information in a formatted and organised manner. Student Marks Report
Remember the relationship:

Table → stores data
Query → retrieves selected data
Form → enters and views data conveniently
Report → presents data in a formatted way

Complete Database Workflow

The complete database workflow helps us understand how the objects work together.

Example: Student Database

Step 1 – Table: Student information is stored in the Students table.

Step 2 – Query: A query selects students according to a condition, such as Marks > 80.

Step 3 – Form: A form can be used to enter or edit student information easily.

Step 4 – Report: A report presents the selected information in an organised format.

Therefore, tables, queries, forms and reports are not completely separate concepts. They perform different functions within the same database system.

Common Practical Mistakes

  • Selecting the wrong table or query as the data source.
  • Forgetting to select an important field.
  • Selecting unnecessary fields.
  • Choosing the wrong grouping field.
  • Using the wrong sorting order.
  • Not checking the report layout.
  • Using portrait orientation when too many columns are required.
  • Giving the report an unclear name.
  • Not checking the final report after creation.
  • Printing without checking the layout.
  • Editing a report without saving the changes.
  • Confusing a report with a table or form.
Important: A report is mainly used for presenting database information. It should not be confused with a form, whose main purpose is convenient data entry and viewing.

Important Questions

Q1. What is a report?

A report is a database object used to present selected database information in a structured and formatted manner suitable for viewing or printing.

Q2. What is the purpose of a report?

The purpose of a report is to present database information clearly, organise records, and provide a formatted view suitable for reading, sharing or printing.

Q3. What is Report Wizard?

Report Wizard is a guided tool in LibreOffice Base that helps users create reports by selecting fields, grouping, sorting, layout and other report settings step by step.

Q4. What is grouping in a report?

Grouping is the process of arranging records together according to a common field or category.

Q5. What is sorting?

Sorting is the process of arranging records according to a selected field in ascending or descending order.

Q6. What is the difference between ascending and descending order?

Ascending order generally arranges text from A to Z and numbers from smaller to larger values. Descending order generally arranges text from Z to A and numbers from larger to smaller values.

Q7. Can a query be used as a data source for a report?

Yes. A query can be used as a data source when the report needs selected records or selected fields instead of all information from a table.

Q8. Differentiate between a form and a report.

A form provides a user-friendly interface for entering, viewing and editing database records, whereas a report presents database information in an organised and formatted layout mainly for viewing and printing.

Q9. What is the importance of report layout?

Report layout determines how information is arranged on the page. A suitable layout improves readability and presentation.

Q10. Why should a report be checked before printing?

A report should be checked before printing to ensure that all required information is present, properly arranged, readable and not cut off due to unsuitable layout or page settings.

Application-Based Questions

Q1. A school has a Students table containing thousands of records. The principal wants a printed list of students grouped according to class. Which database object should be used?

A Report should be used because it can present database information in a formatted layout and group records according to Class.

Q2. A teacher wants a list containing only students who scored more than 80 marks and wants to present it in a formatted document. What can be used?

A query can first select students whose marks are greater than 80, and a report can then present the selected information.

Q3. A report contains many columns and the information is being cut off on the page. What should the user consider changing?

The user should review the report layout and consider using a suitable orientation such as landscape, if appropriate, so that the columns can fit more effectively.

Q4. A student has created a report but the names are not arranged alphabetically. What setting should be checked?

The sorting setting should be checked. The Name field should be selected with ascending order if alphabetical A-to-Z arrangement is required.

Q5. A database administrator wants users to enter student data easily. Should a report be used for this purpose?

No. A form is more suitable because forms provide a user-friendly interface for entering and editing database information.
