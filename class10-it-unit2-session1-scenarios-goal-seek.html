1. Introduction to Data Analysis

A spreadsheet is not only used for entering and storing data. It can also help us analyse data, compare different possibilities, calculate summaries, and make better decisions.

Formal Definition:
Data analysis in a spreadsheet is the process of examining, organizing, summarizing, comparing, and interpreting data with the help of formulas, functions, and spreadsheet tools.
Simple Definition:
Data analysis means studying the data in a spreadsheet so that we can understand it and make useful decisions from it.

Why Do We Need Data Analysis?

  • To understand large amounts of data.
  • To calculate totals and averages.
  • To compare different sets of data.
  • To find patterns and useful information.
  • To study different possible situations.
  • To find the input required to achieve a particular result.
  • To support decision-making.
Example:

Suppose a shopkeeper has sales data for January, February and March. Instead of checking every entry separately, the shopkeeper can consolidate the data, calculate subtotals, create different sales scenarios and use Goal Seek to find the sales required to achieve a particular profit.

2. Consolidating Data

Formal Definition:
Consolidating data means combining data from multiple cell ranges or worksheets into one summary range and applying a selected function such as Sum, Average, Count, Maximum or Minimum.
Simple Definition:
Consolidation means collecting information from different places and bringing it together into one summary.

Why Is Data Consolidation Used?

  • To combine information from different worksheets.
  • To prepare a summary from several data ranges.
  • To calculate totals from different sources.
  • To compare information from different departments or periods.
  • To reduce the need for repeated manual calculations.

Example of Consolidation

Suppose a school maintains separate sheets for three months:

Product January February March
Books 500 600 700
Copies 400 450 500

Consolidation can be used to prepare a single summary of these different monthly data ranges.

Important Terms in Consolidation

Term Meaning
Source Data Range The cell range from which data is taken for consolidation.
Consolidation Range The list of source ranges that will be combined.
Target Range The location where the consolidated result will be displayed.
Function The calculation applied to the selected data, such as Sum, Average, Count, Maximum or Minimum.
Link to Source Data An option that keeps the result connected to the source data so that changes in the source can update the result.

Common Functions Used for Consolidation

  • Sum: Adds the values.
  • Average: Calculates the arithmetic average.
  • Count: Counts numerical entries.
  • Max: Finds the highest value.
  • Min: Finds the lowest value.
  • Product: Multiplies values.
  • Count Numbers: Counts numeric values.

Ways of Consolidating Data

LibreOffice Calc can consolidate data according to the position of the data or according to matching labels.

1. Consolidation by Position

Data is combined according to the same cell positions in the selected ranges.

2. Consolidation by Row Labels

Calc matches identical row labels and combines the corresponding data.

3. Consolidation by Column Labels

Calc matches identical column labels and combines the corresponding data.

Important: When consolidating by row or column labels, the labels should match correctly. If labels are written differently, Calc may treat them as different labels.

3. Practical: How to Consolidate Data in LibreOffice Calc

The following practical demonstrates how to combine data from different ranges into one summary.

Step 1: Open LibreOffice Calc

  1. Start your computer.
  2. Open LibreOffice.
  3. Select Calc Spreadsheet.
  4. Wait for the spreadsheet window to open.

Step 2: Prepare the Source Data

  1. Create or open a spreadsheet containing the first data range.
  2. Enter proper headings.
  3. Enter the required numerical values.
  4. Create another data range if the information is stored separately.
  5. Make sure the data is organized clearly.

Step 3: Select the Destination

  1. Move to the worksheet where you want the final summary.
  2. Click the cell where the consolidated result should begin.
  3. For example, select cell A1.

Step 4: Open the Consolidate Dialog Box

  1. Go to the Data menu.
  2. Click Consolidate.
  3. The Consolidate dialog box will open.
Menu Path: Data → Consolidate

Step 5: Select the Function

  1. Find the Function drop-down list.
  2. Choose the required function.
  3. For a total, select Sum.
  4. For an average, select Average.
  5. Select another function if required.

Step 6: Select the First Source Range

  1. Click inside the Source data range box.
  2. Type the range manually if you know the cell references.
  3. Alternatively, select the required range using the mouse.
  4. Check that the correct range is selected.
  5. Click Add.

Step 7: Add More Source Ranges

  1. Select the second source range.
  2. Click Add.
  3. Repeat the process for additional ranges.
  4. Check the Consolidation ranges list.

Step 8: Select the Target Range

  1. Find Copy results to.
  2. Click inside the field.
  3. Enter the destination cell reference.
  4. Alternatively, click the destination cell in the sheet.
  5. Make sure the destination does not contain important data that you do not want to overwrite.

Step 9: Use Additional Options

  1. Click More if additional options are required.
  2. Select Link to source data if the result should remain connected to the source ranges.
  3. Select Row labels if consolidation should be based on matching row labels.
  4. Select Column labels if consolidation should be based on matching column labels.

Step 10: Complete the Consolidation

  1. Review the function.
  2. Review the source ranges.
  3. Review the destination.
  4. Review the selected options.
  5. Click OK.
  6. Calc will create the consolidated result.
Practical Tip: Always verify the source ranges before clicking OK. Selecting the wrong range is one of the most common mistakes in data consolidation.

4. Groups and Subtotals

Formal Definition – Group:
A group is a collection of related records that have a common value in a particular field or column.
Simple Meaning:
Grouping means putting similar records together.
Formal Definition – Subtotal:
A subtotal is an intermediate calculation made for a particular group of records before the final grand total is calculated.
Simple Meaning:
A subtotal tells us the total for each group separately.

Example

Region Product Sales
North Books 5000
North Copies 3000
South Books 4000
South Copies 2500

A subtotal can calculate the total sales for North separately and South separately, followed by a grand total.

Why Are Subtotals Useful?

  • They summarize large tables.
  • They make group-wise analysis easier.
  • They show intermediate totals.
  • They provide a grand total.
  • They help in comparing different groups.
  • They can organize large datasets automatically.

Important Subtotal Functions

Function Purpose
SUM Adds values in a group.
AVERAGE Calculates the average of values.
COUNT Counts numerical entries.
MAX Finds the highest value.
MIN Finds the lowest value.
PRODUCT Multiplies values.

5. Practical: Creating Subtotals in LibreOffice Calc

Step 1: Prepare the Data

  1. Open LibreOffice Calc.
  2. Open the spreadsheet containing the data.
  3. Make sure the first row contains proper column headings.
  4. Make sure the data is arranged in rows and columns.
  5. Check that there are no unnecessary blank rows inside the dataset.

Step 2: Select the Data Range

  1. Select the complete data range.
  2. Include the column headings.
  3. Alternatively, click inside the data area if Calc can identify the complete database range automatically.

Step 3: Open Subtotals

  1. Go to the Data menu.
  2. Choose Subtotals.
  3. The Subtotals dialog box will open.
Menu Path: Data → Subtotals

Step 4: Select the Grouping Column

  1. Open the 1st Group tab.
  2. Find the Group by list.
  3. Select the column by which you want to create groups.
  4. For example, select Region.

Step 5: Select the Column for Calculation

  1. Find Calculate subtotals for.
  2. Select the numerical column.
  3. For example, select Sales.

Step 6: Select the Function

  1. Find the Use function list.
  2. Select Sum for total sales.
  3. Select another function if required.

Step 7: Add More Calculations

  1. You can select more than one numerical column.
  2. Choose the required function for each selected column.
  3. Review the selections carefully.

Step 8: Use Second and Third Groups

  1. Open the 2nd Group tab if another level of grouping is required.
  2. Select another grouping column.
  3. Select the columns to calculate.
  4. Select the required function.
  5. The same process can be repeated using the 3rd Group tab when needed.

Step 9: Check Options

  1. Open the Options tab.
  2. Check the available sorting and presentation options.
  3. You may use pre-sorting according to the selected group.
  4. You may choose whether the summary should appear above or below the data.
  5. Use the required options according to the practical question.

Step 10: Apply the Subtotals

  1. Review all settings.
  2. Click OK.
  3. Calc will create subtotal rows.
  4. A grand total will also be calculated.
  5. An outline may appear at the left side of the sheet.

Working with the Subtotal Outline

The outline on the left can be used to show or hide different levels of detail.

  • Detailed level shows individual records.
  • Higher-level views can show only summaries.
  • Plus (+) and minus (-) controls can expand or collapse groups.

Deleting Subtotals

  1. Select the area containing the subtotals.
  2. Go to Data → Subtotals.
  3. Open the Subtotals dialog.
  4. Click Delete.
  5. The subtotal rows will be removed.

6. What-if Analysis

Formal Definition:
What-if analysis is a method of examining how changing one or more input values affects the result of a calculation.
Simple Definition:
What-if analysis means asking, “What will happen if I change this value?”

Example

Suppose a business calculates profit using sales and expenses.

Profit = Sales - Expenses

We can ask:

  • What if sales increase?
  • What if expenses increase?
  • What if sales decrease?
  • What if both sales and expenses change?

Basic Elements of What-if Analysis

Element Meaning
Input / Variable Cell The value that may be changed.
Formula Cell The cell containing the formula that calculates the result.
Result The value produced after calculation.
Scenario A named set of possible input values.

7. What-if Scenarios

Formal Definition:
A scenario in LibreOffice Calc is a named set of cell values that can be used in calculations and switched between different sets to observe different results.
Simple Definition:
A scenario is a saved set of possible values that allows us to compare different situations quickly.

Why Use Scenarios?

  • To compare different possibilities.
  • To avoid entering values repeatedly.
  • To study best-case and worst-case situations.
  • To examine the effect of changing assumptions.
  • To support planning and decision-making.

Example: Sales Planning

Situation Units Sold Price
Low Sales 500 100
Normal Sales 800 100
High Sales 1200 100

Instead of manually changing the units every time, different scenarios can be created and switched between.

Important Scenario Terms

  • Scenario Name: The name used to identify a scenario.
  • Changing Cells: The cells whose values differ between scenarios.
  • Scenario Values: The values stored for the selected changing cells.
  • Scenario Result: The output produced after applying a scenario.

8. Practical: Creating a What-if Scenario

Step 1: Create the Spreadsheet

  1. Open LibreOffice Calc.
  2. Enter the required labels and values.
  3. Create a formula that uses the values which may change.
  4. Check that the formula produces the expected result.

Step 2: Identify the Changing Cells

  1. Look at the formula and identify which input values may change.
  2. Select the cells containing those values.
  3. If multiple cells are required, select all of them.

Step 3: Open Scenario Creation

  1. Keep the required changing cells selected.
  2. Go to the Tools menu.
  3. Choose Scenarios.
  4. The Create Scenario dialog will appear.
Menu Path: Tools → Scenarios

Step 4: Enter the Scenario Name

  1. Enter a meaningful scenario name.
  2. For example, type Low Sales.
  3. Use a name that clearly describes the situation.
  4. Review the other available settings.
  5. Click OK.

Step 5: Create Another Scenario

  1. Select the same changing cells.
  2. Choose Tools → Scenarios again.
  3. Enter another name, such as Normal Sales.
  4. Enter or use the required values for that scenario.
  5. Click OK.

Step 6: Create a Third Scenario

  1. Select the changing cells again.
  2. Open Tools → Scenarios.
  3. Enter High Sales.
  4. Enter the required values.
  5. Click OK.

Using a Scenario

  1. Open the Navigator.
  2. Locate the Scenarios section.
  3. Find the scenario names.
  4. Double-click a scenario name.
  5. The corresponding values will be applied to the selected cells.
  6. Observe the changed result.

Editing a Scenario

  1. Open the Navigator.
  2. Open the Scenarios section.
  3. Right-click the scenario.
  4. Select Properties.
  5. Make the required changes.
  6. Save the changes.

Deleting a Scenario

  1. Open the Navigator.
  2. Locate the scenario.
  3. Right-click the scenario name.
  4. Select Delete.
  5. Confirm the deletion if prompted.
Important: A scenario is useful when you want to store and switch between several possible sets of values. It is different from manually changing a value and forgetting the previous value.

10. Goal Seek

Formal Definition:
Goal Seek is a spreadsheet analysis tool used to find the value of one variable input that produces a specified result in a formula.
Simple Definition:
Goal Seek works backwards. Instead of asking what result a particular input will produce, we tell Calc the result we want and ask it to find the input required to achieve that result.

Simple Example

Suppose:

Profit = Sales - Expenses

If we want a profit of ₹50,000 and the expense is fixed, Goal Seek can calculate the sales value required to achieve ₹50,000 profit.

Three Important Parts of Goal Seek

Part Meaning
Formula Cell The cell containing the formula whose result we want to control.
Target Value The result that we want the formula cell to achieve.
Variable Cell The input cell whose value Calc is allowed to change to achieve the target.

Goal Seek Works Like This

Normal calculation:

Input → Formula → Result

Goal Seek:

Desired Result → Formula → Required Input

When Should We Use Goal Seek?

  • When there is one important variable input.
  • When the desired result is already known.
  • When we need to calculate the input required for a target.
  • When manual trial-and-error would take too much time.

Examples of Goal Seek

  • Find the sales required for a target profit.
  • Find the marks required to achieve a target percentage.
  • Find the price required to achieve a target revenue.
  • Find the number of units required to reach a target income.
  • Find the interest rate required to reach a target amount.

11. Practical: Using Goal Seek in LibreOffice Calc

This is one of the most important practical procedures of this session. Follow each step carefully.

Practical Example: Finding Required Sales

Suppose a business has:

Cell Content
A1 Sales
B1 100000
A2 Expenses
B2 60000
A3 Profit
B3 =B1-B2

The current profit is ₹40,000. Suppose we want the profit to become ₹50,000. We can use Goal Seek to find the required sales.

Step 1: Open LibreOffice Calc

  1. Open LibreOffice.
  2. Select Calc Spreadsheet.
  3. Wait for the spreadsheet to open.

Step 2: Enter the Data

  1. Click cell A1.
  2. Type Sales.
  3. Press Enter.
  4. Click B1.
  5. Enter the current sales value.
  6. Enter the expense value in B2.
  7. Enter the appropriate labels in column A.

Step 3: Create the Formula

  1. Click the cell where the profit should appear.
  2. Type the formula using cell references.
  3. For example, type:
=B1-B2
  1. Press Enter.
  2. Check that the profit is calculated correctly.

Step 4: Identify the Formula Cell

  1. Look at the profit cell.
  2. This cell contains the formula.
  3. Remember its cell reference.
  4. In our example, it is B3.

Step 5: Identify the Variable Cell

  1. Decide which value Calc should change.
  2. In our example, we want Calc to change Sales.
  3. The sales value is stored in B1.
  4. Therefore, B1 is the variable cell.

Step 6: Open Goal Seek

  1. Go to the Tools menu.
  2. Select Goal Seek.
  3. The Goal Seek dialog box will open.
Menu Path: Tools → Goal Seek

Step 7: Enter the Formula Cell

  1. Find the Formula Cell field.
  2. Enter the reference of the cell containing the formula.
  3. In this example, enter B3.
  4. You can also select the cell directly from the worksheet.

Step 8: Enter the Target Value

  1. Find the Target Value field.
  2. Enter the result you want.
  3. For example, enter 50000.
  4. This means we want the formula cell to produce 50,000.

Step 9: Enter the Variable Cell

  1. Find the Variable Cell field.
  2. Enter the cell whose value should change.
  3. In our example, enter B1.
  4. Check that the variable cell is the correct input cell.

Step 10: Start Goal Seek

  1. Check all three fields.
  2. Formula Cell must contain the formula cell.
  3. Target Value must contain the desired result.
  4. Variable Cell must contain the input cell that can change.
  5. Click OK.

Step 11: Examine the Result

  1. Calc performs the Goal Seek calculation.
  2. A result dialog will appear.
  3. Check the proposed value for the variable cell.
  4. Check whether the target value has been reached.

Step 12: Accept the Result

  1. If the result is correct, choose the option to apply the result.
  2. Calc will place the calculated value in the variable cell.
  3. The formula cell will recalculate automatically.
  4. Check the final result.

Step 13: Verify the Calculation

  1. Look at the changed variable cell.
  2. Look at the formula cell.
  3. Confirm that the formula now produces the target value.
  4. If necessary, manually check the calculation.
Important: Goal Seek changes the value of the selected variable cell. Therefore, save the original value separately if you need to preserve the original data for comparison.

12. Important Goal Seek Concepts

Question Answer
What is the Formula Cell? The cell containing the formula whose result must reach the target.
What is the Target Value? The desired result that we want the formula to produce.
What is the Variable Cell? The input cell whose value can be changed to achieve the target.
Can Goal Seek change several variable cells at the same time? Goal Seek is designed around one variable cell. Problems involving multiple changing variables and constraints are better suited to Solver.
Does Goal Seek work without a formula? No. There must be a formula cell whose result can respond to the variable cell.
What does Goal Seek calculate? It calculates the input value required to achieve a specified formula result.

13. Solver

Formal Definition:
Solver is an advanced spreadsheet optimization tool used to find values for variable cells that satisfy a target condition while considering constraints.
Simple Definition:
Solver is used when a problem is more complicated than a simple one-variable Goal Seek problem.

Goal Seek vs Solver

Goal Seek Solver
Normally works with one variable cell. Can work with multiple variable cells.
Used to reach a specified formula result. Can optimize a result while considering constraints.
Simple target-based analysis. More advanced optimization.
Easy for basic problems. Useful for complex decision-making problems.
CBSE Note: The current 2026–27 CBSE curriculum lists Goal Seek in the theory topics for this chapter, while the practical outcome also refers to using Goal Seek and Solver. Therefore, students should understand Solver as the related advanced practical tool, while Goal Seek remains a central theory concept.

When Is Solver Useful?

  • When more than one variable needs to change.
  • When there are restrictions or constraints.
  • When the objective is to maximize or minimize a result.
  • For more complex optimization problems.

Opening Solver

Menu Path: Tools → Solver

Solver opens a dialog in which an optimization problem can be defined using an objective cell, variable cells and constraints.

Do not confuse: Goal Seek and Solver are related but not identical. Goal Seek is mainly used to find one input required for a desired formula result, while Solver is intended for more complex optimization involving variables and constraints.

15. Common Mistakes and How to Avoid Them

Mistake How to Avoid It
Selecting the wrong source range Check the cell references before adding the range.
Choosing the wrong consolidation function Select Sum, Average, Count, Max, Min etc. according to the question.
Using different labels during consolidation Use consistent labels when consolidating by labels.
Putting the result in the wrong location Check the Copy results to field.
Wrong Group by column Select the column that actually identifies the groups.
Wrong subtotal column Select the numerical column that needs calculation.
Forgetting to select changing cells for a scenario Select all cells whose values should differ between scenarios.
Wrong Goal Seek Formula Cell Select the cell that actually contains the formula.
Wrong Target Value Enter the result that you actually want to achieve.
Wrong Variable Cell Select the input cell that Calc should change.
Trying Goal Seek without a formula Create a proper formula first.

21. Important Terms at a Glance

Term Meaning
Data Analysis Studying data to obtain useful information and support decisions.
Consolidation Combining data from different ranges into one summary.
Source Range Range from which data is taken.
Target Range Location where the result is placed.
Group Collection of records having a common characteristic.
Subtotal Total calculated for a particular group.
Grand Total Overall total of all groups.
What-if Analysis Studying how changes in inputs affect results.
Scenario A named set of possible input values.
Formula Cell Cell containing the formula whose result is targeted.
Target Value Desired result of the formula.
Variable Cell Input cell whose value is changed to reach the target.
Goal Seek Finds the input required for a specified formula result.
Solver Advanced optimization tool using variables and constraints.
