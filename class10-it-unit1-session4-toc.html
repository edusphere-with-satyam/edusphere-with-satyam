SESSION 4: CREATE AND CUSTOMIZE TABLE OF CONTENTS

Class 10 Information Technology (402) | Unit 1 – Digital Documentation (Advanced)

📘 Introduction

A long document may contain many chapters, topics and subtopics. Finding a particular topic manually can take time. A Table of Contents (TOC) provides a list of the main headings and subheadings of a document along with their page numbers.

LibreOffice Writer can automatically create a Table of Contents from the headings used in a document. This means that the user does not have to type every heading and page number manually.

In simple words: A Table of Contents is a list of topics and subtopics in a document that helps the reader quickly find a particular section.

📑 What is a Table of Contents?

Formal Definition:
A Table of Contents is an automatically generated list of the headings and subheadings of a document, usually displayed with their corresponding page numbers.
Simple Definition:
A Table of Contents is like a map of a document. It tells the reader what topics are present and where they can be found.

Example

1. Introduction ............... 1
2. Digital Documentation ....... 3
3. Styles ...................... 7
4. Images ...................... 12

The actual entries and page numbers are generated according to the headings and document structure.

⭐ Why is a Table of Contents Used?

  • It gives an overview of a long document.
  • It helps readers locate topics quickly.
  • It saves time when searching for a particular section.
  • It gives the document a professional appearance.
  • It automatically displays page numbers.
  • It can be updated when the document changes.
  • It reduces the need to prepare the contents list manually.

🏷️ Heading Styles and Table of Contents

Before creating a Table of Contents, headings should be properly identified using heading paragraph styles.

Heading Style:
A heading style is a predefined paragraph style used to identify and format headings at different levels in a document.

Common Heading Levels

Heading 1: Usually used for major chapters or main sections.
Heading 2: Usually used for subsections inside a Heading 1 section.
Heading 3: Usually used for smaller subsections inside a Heading 2 section.
Example:

Heading 1 → Digital Documentation
Heading 2 → Working with Images
Heading 3 → Resizing Images
Important: The predefined heading styles such as Heading 1, Heading 2 and Heading 3 provide the structure from which LibreOffice can generate the Table of Contents.

🛠️ Applying a Heading Style

The following steps can be used to apply a heading style before creating the Table of Contents.

Step 1: Open the required document in LibreOffice Writer.
Step 2: Locate the heading that you want to include in the Table of Contents.
Step 3: Click anywhere inside that heading paragraph.
Step 4: Open the paragraph style list or Styles interface.
Step 5: Select the appropriate heading style.
Step 6: For a main section, select Heading 1.
Step 7: For a subsection, select Heading 2.
Step 8: For a smaller subsection, select Heading 3.
Step 9: Repeat these steps for the other headings in the document.
Tip: Do not create a TOC by manually typing the headings and page numbers. Proper heading styles allow Writer to generate the TOC automatically.

🛠️ Creating a Table of Contents

Once the headings have been properly formatted, the Table of Contents can be inserted into the document.

Step-by-Step Procedure

Step 1: Open the document in LibreOffice Writer.
Step 2: Make sure that the required headings have appropriate heading styles.
Step 3: Decide where the Table of Contents should appear.
Step 4: Click at the location where you want to insert the TOC.
Step 5: Open the Insert menu.
Step 6: Select Table of Contents and Index.
Step 7: Select Table of Contents, Index or Bibliography.
Step 8: The Table of Contents dialog box will appear.
Step 9: Make sure that the type is set to Table of Contents.
Step 10: Check the available options according to your requirement.
Step 11: Check the heading levels that should be included.
Step 12: Click OK.
Step 13: LibreOffice generates the Table of Contents at the selected location.
Step 14: Check the headings displayed in the TOC.
Step 15: Check the page numbers.
LibreOffice creates TOC entries from the outline level of the paragraph style and the heading text.

🔢 Include Up to Level

Meaning:
The Include up to level option determines how many heading levels are included in the Table of Contents.
Level 1: Includes major headings.
Level 2: Includes Level 1 and Level 2 headings.
Level 3: Includes Level 1, Level 2 and Level 3 headings.
Example:
If you want only chapters, use a lower level. If you want chapters, sections and subsections, include more heading levels.

🎨 Customizing the Table of Contents

LibreOffice provides options for changing the way the Table of Contents appears.

Changing the Title

Step 1: Place the cursor inside the Table of Contents.
Step 2: Open the Table of Contents editing options.
Step 3: Open the Type tab if necessary.
Step 4: Locate the Title field.
Step 5: Enter the required title.
Step 6: Apply the change.

Changing the Number of Heading Levels

Step 1: Open the Table of Contents editing dialog.
Step 2: Locate Include up to level.
Step 3: Select the required level.
Step 4: Apply the changes.

Changing Entry Structure

Step 1: Open the Table of Contents editing dialog.
Step 2: Select the Entries tab.
Step 3: Select the heading level that you want to customize.
Step 4: Use the structure and formatting controls to adjust how the entry is displayed.
Step 5: Add, remove or replace available structure elements where required.
Step 6: Apply the changes.
The Entries tab allows the structure of TOC entries to be customized. LibreOffice provides codes and controls for changing the structure and formatting of entries.

➕ Using Additional Styles in a Table of Contents

LibreOffice normally creates TOC entries from heading levels. However, other paragraph styles can also be assigned to TOC levels when required.

Step 1: Open the Table of Contents dialog.
Step 2: Go to the Type tab.
Step 3: Locate the Create from area.
Step 4: Select Additional Styles.
Step 5: Click Assign Styles.
Step 6: Select the paragraph style that you want to include.
Step 7: Assign an appropriate TOC level.
Step 8: Confirm the style assignment.
Step 9: Apply the changes to the Table of Contents.
This is an advanced option. For normal Class 10 work, using Heading 1, Heading 2 and Heading 3 is generally sufficient.

🔄 Updating the Table of Contents

A document may change after the Table of Contents has been created. New headings may be added, headings may be removed, or page numbers may change. The TOC should therefore be updated.

Method 1 – Right-Click Method

Step 1: Locate the Table of Contents.
Step 2: Right-click inside the Table of Contents.
Step 3: Select Update Index or Table of Contents.
Step 4: LibreOffice updates the TOC.

Method 2 – Tools Menu

Step 1: Open the Tools menu.
Step 2: Select Update.
Step 3: Select All Indexes and Tables when required.
Remember: Whenever headings or page positions change, update the TOC so that its entries and page numbers remain current.

✏️ Editing the Table of Contents

The properties and structure of an existing Table of Contents can be changed.

Step 1: Click inside the Table of Contents.
Step 2: Right-click inside the TOC.
Step 3: Select Edit Index or Table of Contents.
Step 4: Make the required changes in the dialog box.
Step 5: Change the required title, levels, entries or other available options.
Step 6: Apply the changes.
Step 7: Check the updated Table of Contents.
If the TOC is protected against manual changes, its generated contents should be changed through the appropriate TOC settings rather than by manually editing generated entries.

🗑️ Deleting the Table of Contents

Step 1: Click inside the Table of Contents.
Step 2: Right-click the Table of Contents.
Step 3: Select the option to delete or remove the Table of Contents.
Step 4: Confirm the operation if LibreOffice asks for confirmation.
Important: Removing the TOC removes the generated Table of Contents, not the actual headings and main content of your document.

⚠️ Common Mistakes

1. Why is my heading not appearing in the Table of Contents?
▶ View Explanation
Check whether the heading has been given an appropriate heading style or outline level. Also check whether the TOC has been updated after making changes.
2. Why are old page numbers showing in the TOC?
▶ View Explanation
The document may have changed after the TOC was created. Right-click the TOC and choose Update Index or Table of Contents.
3. Why are too many subheadings appearing in the TOC?
▶ View Explanation
The selected heading level may be too high. Reduce the Include up to level setting according to the required document structure.

🧪 Practical Activity: Create and Customize a Table of Contents

Create a small project document containing headings and subheadings and generate a Table of Contents from them.

Part A – Prepare the Document

Step 1: Open LibreOffice Writer.
Step 2: Create a new blank document.
Step 3: Type a suitable title for the project.
Step 4: Create a few main sections.
Step 5: Create a few subtopics under the main sections.
Step 6: Click inside the first main heading.
Step 7: Apply Heading 1.
Step 8: Repeat this for the other main headings.
Step 9: Click inside each subheading.
Step 10: Apply Heading 2 to the subheadings.

Part B – Insert the Table of Contents

Step 11: Place the cursor where the Table of Contents should appear.
Step 12: Open the Insert menu.
Step 13: Select Table of Contents and Index.
Step 14: Select Table of Contents, Index or Bibliography.
Step 15: Make sure the type is Table of Contents.
Step 16: Select the required heading level.
Step 17: Click OK.
Step 18: Check whether all required headings appear.
Step 19: Check the page numbers.

Part C – Make a Change and Update

Step 20: Add a new heading to the document.
Step 21: Apply the appropriate heading style to the new heading.
Step 22: Change the document so that page positions may change.
Step 23: Right-click inside the Table of Contents.
Step 24: Select Update Index or Table of Contents.
Step 25: Check whether the new heading and updated page number appear.

Part D – Customize

Step 26: Right-click inside the Table of Contents.
Step 27: Select Edit Index or Table of Contents.
Step 28: Change the required TOC option.
Step 29: Apply the changes.
Step 30: Check the final appearance of the Table of Contents.
Result: You have created, updated and customized a Table of Contents in LibreOffice Writer.

🧠 Application-Based Questions

1. A student has prepared a 20-page project and wants readers to quickly find each chapter. What should the student create?
▶ View Answer
The student should create a Table of Contents containing the document's main headings and subheadings with their page numbers.
2. A heading is present in the document but does not appear in the Table of Contents. What should be checked?
▶ View Answer
The student should check whether the heading has been assigned an appropriate heading style or outline level. The Table of Contents should also be updated.
3. A project has chapters, sections and subsections. Which heading styles can be used?
▶ View Answer
Heading 1 can be used for chapters, Heading 2 for sections and Heading 3 for subsections.
4. A student added a new chapter after creating the TOC. The new chapter is not shown. What should be done?
▶ View Answer
Apply the appropriate heading style to the new chapter and then update the Table of Contents.

🎯 Important Questions

1. Define Table of Contents.
▶ View Answer
A Table of Contents is a list of headings and subheadings in a document, generally displayed with their corresponding page numbers.
2. Why are heading styles important while creating a Table of Contents?
▶ View Answer
Heading styles identify the structure and hierarchy of the document. LibreOffice uses these heading levels to generate the Table of Contents automatically.
3. Write the steps to create a Table of Contents.
▶ View Answer
Place the cursor at the required location → Insert → Table of Contents and Index → Table of Contents, Index or Bibliography → select the required options → click OK.
4. How can a Table of Contents be updated?
▶ View Answer
Right-click inside the Table of Contents and select Update Index or Table of Contents.
5. What is the purpose of the “Include up to level” option?
▶ View Answer
It determines the maximum heading level that will be included in the Table of Contents.
6. How can an existing Table of Contents be edited?
▶ View Answer
Click or right-click inside the Table of Contents and select Edit Index or Table of Contents. The required settings can then be changed.
7. Differentiate between Heading 1 and Heading 2.
▶ View Answer
Heading 1 is generally used for major sections or chapters, while Heading 2 is generally used for subsections under a Heading 1.
8. What happens to a Table of Contents when page positions change?
▶ View Answer
The Table of Contents should be updated so that the displayed page numbers reflect the current document structure.
