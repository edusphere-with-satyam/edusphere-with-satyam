Introduction to Forms

A database table stores information in rows and columns. However, entering and viewing data directly in a table may not always be convenient, especially when the database contains many fields or records.

A form provides a user-friendly way to enter, view and manage information stored in a database.

Formal Definition:
A form is a database object that provides a user interface for entering, viewing and modifying data stored in database tables.
Simple Definition:
A form is a user-friendly screen through which we can enter and manage database information without working directly with the table.
📌 Example – Student Registration Form

A school may have a Students table containing Student_ID, Name, Class, Section and Marks.

Instead of entering information directly into rows of the table, a form can provide separate boxes for:

  • Student ID
  • Student Name
  • Class
  • Section
  • Marks

The user can enter the student's information through these fields and the data can be stored in the underlying table.

Understanding a Database Form

A form acts as an interface between the user and the database. It presents database fields in an organised and easier-to-use format.

Basic flow:

User → Form → Database Table

When a user enters information through a form, the information can be stored in the related table. Similarly, existing records can be displayed through the form.

Important Parts of a Form

  • Label: Displays information such as "Name" or "Marks" to identify a field.
  • Control: An element through which the user interacts with the form.
  • Field: Represents a particular type of data stored in the database.
📌 Example – How a Form Works

Suppose the form contains a text box labelled Name.

When the user enters Rahul in that box, the value is associated with the Name field of the related database record.

Uses of Forms

Forms make interaction with a database easier and more organised. Some important uses are:

  • Entering new records.
  • Viewing existing records.
  • Editing existing information.
  • Moving between database records.
  • Providing a simple interface for users.
  • Reducing the need to work directly with database tables.
  • Making data entry more organised.
📌 Example – School Database

A school clerk may use a student form to enter student information instead of opening the table every time.

The form can provide clearly labelled fields, making the data-entry process easier and reducing confusion.

Form Controls

Form controls are elements placed on a form that display information or allow the user to enter and select data.

Text Box

A text box allows the user to enter or display text or other values.

Label

A label identifies a field or provides information to the user. For example, Name can be used as a label for a student's name field.

Check Box

A check box is generally used when an option can be selected or cleared independently.

Option Button

An option button is generally used when the user needs to choose one option from a group of mutually exclusive options.

List Box

A list box displays a list of available choices from which the user can select.

Combo Box

A combo box combines a text-entry area with a list of available choices, depending on how it is configured.

📌 Example – Controls in a Student Form
  • Name: Text box
  • Class: List or combo box
  • Section: List or combo box
  • Gender/Category choice: Option buttons, where appropriate
  • Activity participation: Check box, where appropriate

Form Wizard

Formal Definition:
Form Wizard is a guided tool in LibreOffice Base that helps users create a form by selecting a table or query, fields and layout options through a sequence of steps.
Simple Definition:
Form Wizard helps us create a form step by step without designing every part manually.

It is especially useful for beginners because the wizard provides a structured process for selecting fields and arranging the form.

🛠️ Practical Steps – Creating a Form Using Form Wizard
  1. Open SchoolDatabase in LibreOffice Base.
  2. Select the Forms section.
  3. Choose Use Wizard to Create Form.
  4. Select the required table or query.
  5. Select the fields that you want to include in the form.
  6. Move to the next step of the wizard.
  7. Select an appropriate layout for the form.
  8. Choose the required data-entry options.
  9. Select a suitable style if available.
  10. Give the form a meaningful name.
  11. Finish the wizard.
  12. Open the form and check whether it works correctly.

Creating a Form for the Students Table

We can create a form using the Students table created in Session 1.

The table contains fields such as: Student_ID, Name, Class, Section and Marks.

🛠️ Practical Steps – Create a Student Form
  1. Open SchoolDatabase.
  2. Open the Forms section.
  3. Start the Form Wizard.
  4. Select the Students table.
  5. Select Student_ID, Name, Class, Section and Marks.
  6. Choose a suitable form layout.
  7. Complete the remaining wizard options.
  8. Give the form a meaningful name such as StudentForm.
  9. Finish the wizard.
  10. Open the form and check the displayed fields.

Entering Data Through a Form

One of the main purposes of a form is to make data entry easier. Instead of entering values directly into a table, the user can enter information through clearly labelled controls.

When a new record is entered correctly and saved, the information becomes part of the related database table.

🛠️ Practical Steps – Enter a New Student Record
  1. Open the StudentForm.
  2. Move to the position for entering a new record.
  3. Enter the Student_ID.
  4. Enter the student's Name.
  5. Enter the Class.
  6. Enter or select the Section.
  7. Enter the Marks.
  8. Check the entered information.
  9. Save or move to another record so that the new record is stored.
Tip: Always check important values such as Student_ID and Marks before saving a record.

Viewing and Navigating Records

A form can be used to move through records stored in the database. Record navigation allows the user to view different records without manually searching through the entire table.

Navigation controls commonly allow movement to the first, previous, next and last record.

🛠️ Practical Steps – Navigate Through Records
  1. Open the StudentForm.
  2. Locate the record navigation controls.
  3. Use the First Record control to go to the first record.
  4. Use Next Record to move forward.
  5. Use Previous Record to move backward.
  6. Use Last Record to move to the final record.

Editing Records Through a Form

Existing information may sometimes need to be corrected or updated. A form can be used to locate a record and modify its information.

🛠️ Practical Steps – Edit a Record
  1. Open the StudentForm.
  2. Navigate to the record that needs modification.
  3. Click the required field.
  4. Change the incorrect or outdated information.
  5. Check the modified information.
  6. Save the record.
Important: Before changing a record, make sure that you are editing the correct student or record.

Deleting Records Through a Form

Sometimes a record may need to be removed from a database. Deleting a record should be done carefully because the record may no longer be available after deletion.

🛠️ Practical Steps – Delete a Record
  1. Open the StudentForm.
  2. Navigate to the record that needs to be deleted.
  3. Verify that it is the correct record.
  4. Use the appropriate delete-record command.
  5. Confirm the deletion if LibreOffice asks for confirmation.
  6. Check the remaining records.
Remember: Do not delete a record unless you are sure that it is no longer required or that deletion is authorised.

Form Design and Design View

A form can be modified after it has been created. Design View allows the user to work with the controls and layout of a form.

Basic form design may include moving controls, changing their size, changing labels and arranging information in a clearer way.

🛠️ Practical Steps – Basic Form Customization
  1. Open the required form in Design View.
  2. Select the control that you want to modify.
  3. Move the control to the required position.
  4. Resize the control if necessary.
  5. Modify the label or displayed text where required.
  6. Arrange related controls in a logical order.
  7. Save the form.
  8. Open the form normally and check its appearance.

Form vs Table

Table Form
Mainly stores data. Provides an interface for working with data.
Displays data in rows and columns. Displays information using controls and fields.
Can be less convenient for beginners. Provides a more user-friendly interface.
Used as a main data storage object. Used for entering, viewing and modifying data.

Common Practical Mistakes

  • Selecting the wrong table while creating the form.
  • Selecting unnecessary or incorrect fields.
  • Giving the form an unclear name.
  • Entering incorrect information in a field.
  • Forgetting to save changes.
  • Editing the wrong record.
  • Deleting a record accidentally.
  • Changing the form layout without checking the final result.
