Introduction to Database Management System

A database is an organised collection of related information that can be stored, managed, searched, and updated efficiently. Databases are used in schools, banks, hospitals, offices, shops, libraries, and many other organisations.

Definition – Database:
A database is an organised collection of related data that can be stored and managed so that information can be easily accessed, updated, and retrieved.
Definition – Database Management System (DBMS):
A Database Management System is software that allows users to create, store, organise, manage, retrieve, and modify data in a database.
In simple words:
A DBMS is software that helps us store and manage large amounts of related information in an organised way.
Example:
A school database may contain information about students such as their name, roll number, class, contact details, and marks.

LibreOffice Base

LibreOffice Base is the database component of the LibreOffice suite. It can be used to create and manage databases and work with database objects such as tables, queries, forms, and reports.

Why Do We Need a Database?

When a large amount of information is stored in an unorganised manner, finding and updating information can become difficult. A database provides a systematic way of managing such information.

  • Stores related information in an organised form.
  • Makes searching for information easier.
  • Allows information to be updated.
  • Helps retrieve required information quickly.
  • Reduces unnecessary duplication of information.
  • Helps maintain large amounts of data efficiently.
Real-life examples:
  • Student records in schools
  • Customer records in banks
  • Patient records in hospitals
  • Books in libraries
  • Product and sales records in shops

Database Objects

A database can contain different objects that perform different tasks. The major database objects studied in this unit include:

Table
Stores data in rows and columns.
Query
Used to retrieve specific information from a database.
Form
Provides a user-friendly way to enter and view data.
Report
Presents database information in an organised format.
