Session 2 – Using Macros in Spreadsheet

Unit 2 – Electronic Spreadsheet (Advanced) using LibreOffice Calc

1. Introduction to Macros

In a spreadsheet, some tasks have to be performed repeatedly. For example, a teacher may need to format the same type of table every week, calculate values in the same way, or sort a list again and again.

Performing the same steps manually every time takes time and may also lead to mistakes. A macro helps automate a sequence of instructions so that a repeated task can be performed more easily.

Formal Definition:
A macro is a recorded or programmed sequence of instructions that can be executed to automate a task in a spreadsheet application.
Simple Definition:
A macro is a set of instructions saved in the spreadsheet so that a repeated task can be performed automatically instead of doing every step manually.

Why Are Macros Used?

  • To automate repetitive tasks.
  • To save time.
  • To reduce repeated manual work.
  • To perform a series of operations quickly.
  • To make repeated spreadsheet work more convenient.
  • To perform calculations or operations using programmed instructions.
Example:
Suppose a teacher receives a student marks sheet every month. If the teacher always has to format the headings, apply borders, adjust the same cells and perform the same operations, a macro can automate these repeated actions.

Examples of Tasks That Can Be Automated

  • Applying repeated formatting.
  • Performing repeated calculations.
  • Changing cell values.
  • Reading values from cells.
  • Sorting data.
  • Performing a sequence of spreadsheet operations.

Advantages of Macros

  • They save time.
  • They reduce repetitive work.
  • They can improve consistency in repeated tasks.
  • They can perform several instructions in sequence.
  • They can be useful for advanced spreadsheet work.

Limitations and Precautions

  • A wrongly created macro can produce incorrect results.
  • A recorded macro may depend on the way the worksheet was prepared.
  • Macros should be tested before being used on important data.
  • Unknown macros should not be enabled blindly.
  • Important spreadsheets should be saved or backed up before testing a new macro.

2. Understanding Macros in LibreOffice Calc

Macro: A macro is a collection of instructions that performs a particular task automatically when it is executed.

In LibreOffice Calc, a macro can contain a series of actions or programming instructions. These instructions tell Calc what operations should be performed.

Macro as a Sequence of Instructions

Think of a macro as a small set of instructions. Instead of telling the computer every step again and again, we save the instructions and execute them whenever required.

Example sequence:
  1. Select a particular range.
  2. Apply formatting.
  3. Change the font.
  4. Apply a border.
  5. Save the operation as a macro.
  6. Run the macro whenever the same type of operation is required.

Macro and Automation

Automation means using a system or program to perform work with less manual intervention.

A macro is one method of automation. Once the required instructions have been recorded or programmed, the user can execute them instead of repeating the entire sequence manually.

LibreOffice Basic

Macros in LibreOffice can be written using LibreOffice Basic, a programming language used for creating macros.

Remember:
A recorded macro is created by recording actions, while a manually created macro can be written using programming instructions.

Formula vs Macro

Formula Macro
Usually performs a calculation in a cell. Can perform a sequence of operations.
Written directly in a cell. Can be recorded or programmed.
Example: =SUM(A1:A5) Can automate several spreadsheet actions.
Primarily works with calculations. Can automate calculations, formatting and other operations.

3. Recording a Macro

Formal Definition:
Recording a macro means capturing a sequence of actions performed by the user and saving those actions as a macro that can be executed later.
Simple Definition:
Macro recording means asking Calc to remember the steps you perform so that you can repeat those steps automatically later.

Basic Process

  1. Open the spreadsheet.
  2. Prepare the worksheet.
  3. Start the macro recorder.
  4. Give the macro a suitable name.
  5. Perform the required actions.
  6. Stop recording.
  7. Save the macro.
  8. Run it to test the result.
Important: Keep the actions simple when learning macro recording. The recorder may not record every possible type of user action in the same way.

4. Practical: Record a Macro

Let us create a simple macro that performs repeated formatting on a small table.

Step 1 – Open LibreOffice Calc

  1. Start your computer.
  2. Open LibreOffice.
  3. Select Calc Spreadsheet.
  4. Wait for the spreadsheet window to open.

Step 2 – Prepare Sample Data

Enter a small table such as:

Name Marks Grade
Rahul 78 B+
Anita 91 A+
Ravi 84 A

Step 3 – Decide What the Macro Will Do

Before recording, decide the exact actions that you want the macro to remember.

For example:

  • Select the heading row.
  • Make the heading bold.
  • Apply a background colour.
  • Align the heading.

Step 4 – Start Macro Recording

  1. Open the Tools menu.
  2. Go to Macros.
  3. Select Record Macro.
  4. The macro recording process will begin.
When recording is active, Calc records supported actions that you perform in the spreadsheet.

Step 5 – Give the Macro a Name

After stopping the recording, LibreOffice will ask you where to save the recorded macro.

Choose a meaningful name, for example:

FormatHeading

Avoid confusing names. A meaningful name helps you identify the macro later.

Step 6 – Select the Library and Module

LibreOffice stores macros inside a structure containing libraries and modules.

  • Library: A collection used to organise macros.
  • Module: A container inside a library where macro procedures and functions can be stored.

Select an appropriate library and module when saving the macro.

Step 7 – Perform the Actions

  1. Select the heading cells.
  2. Click the Bold button.
  3. Apply the required alignment.
  4. Apply the required formatting.
  5. Perform only the actions that you want the macro to remember.

Step 8 – Stop Recording

  1. Open the Tools menu.
  2. Go to Macros.
  3. Select the option to stop recording.

Step 9 – Save the Macro

  1. Choose the required library.
  2. Choose or create the required module.
  3. Enter a meaningful macro name.
  4. Save the macro.

Step 10 – Test the Macro

Run the macro on a suitable worksheet and check whether the recorded actions are performed correctly.

Do not assume that a recorded macro is correct just because it was saved successfully. Always test it.

5. Running a Macro

Definition:
Running a macro means executing the instructions stored inside the macro so that the required task is performed.

Steps to Run a Macro

  1. Open the spreadsheet containing the macro.
  2. Open the Tools menu.
  3. Go to Macros.
  4. Open the macro management/run option.
  5. Select the appropriate library.
  6. Select the appropriate module.
  7. Select the required macro.
  8. Click Run.
  9. Observe the spreadsheet.
  10. Check whether the expected operation has been performed.

What Happens When a Macro Runs?

Calc executes the instructions stored in the macro in the sequence in which they are programmed or recorded.

If a macro was recorded to apply formatting to a selected range, running that macro executes the recorded formatting operations.

6. Practical: Running a Recorded Macro

  1. Open LibreOffice Calc.
  2. Open the spreadsheet containing your saved macro.
  3. Prepare the worksheet on which you want to test the macro.
  4. Open Tools.
  5. Select Macros.
  6. Open the option for running/managing macros.
  7. Locate the library containing your macro.
  8. Open the required module.
  9. Select the macro name.
  10. Click Run.
  11. Observe the worksheet.
  12. Check whether the expected changes appear.
If the result is not correct, check the macro's recorded actions, the selected cells, the worksheet structure and whether the macro was saved correctly.

7. Creating a Simple Macro

Definition:
Creating a simple macro means writing a small set of instructions in LibreOffice Basic to perform a particular task.

Basic Structure of a Macro

Sub MyMacro 'Instructions go here End Sub

Understanding the Structure

  • Sub: Begins a procedure.
  • MyMacro: The name of the macro.
  • Instructions: Commands that tell the computer what to do.
  • End Sub: Indicates the end of the procedure.

Opening the Macro Editor

  1. Open LibreOffice Calc.
  2. Open the Tools menu.
  3. Go to Macros.
  4. Open Organize Macros.
  5. Select Basic.
  6. Select the appropriate library.
  7. Select the required module.
  8. Open the macro editor.

Writing a Simple Macro

  1. Create or select a module.
  2. Create a new macro procedure.
  3. Give the macro a meaningful name.
  4. Write the required instructions between Sub and End Sub.
  5. Save the macro.
  6. Run the macro to test it.

8. Understanding Macro Code

Consider the following simple structure:

Sub MyMacro 'Instructions go here End Sub

Line 1 – Sub MyMacro

This starts a procedure named MyMacro.

Line 2 – Comment

The apostrophe (') is used to write a comment. Comments explain the code to the programmer and are not treated as normal instructions.

Line 3 – End Sub

This indicates the end of the procedure.

Remember:
A macro procedure generally begins with Sub and ends with End Sub.

9. Creating and Organising a Simple Macro

Macro Library

A library is a collection used to organise macros and related Basic code.

Module

A module is a container inside a library where macro procedures and functions can be stored.

Macro

A macro is an individual procedure or function that performs a particular task.

Organisation Structure

Library → Module → Macro/Function

Steps for Organising Macros

  1. Open the macro management window.
  2. Select the appropriate library.
  3. Open the module containing the macro.
  4. Create a new module when a separate group of macros is required.
  5. Give macros meaningful names.
  6. Keep related macros together.
  7. Save the changes.
  8. Delete or modify unnecessary macros carefully.
Meaningful names such as FormatHeading, CalculateTotal or SortMarks are easier to understand than unclear names.

10. Macro as a Function

Formal Definition:
A function is a programmed block that performs a particular operation and can return a value as its result.
Simple Definition:
A function is a piece of code that receives values, performs an operation and gives back a result.

Procedure vs Function

Procedure (Sub) Function
Performs a sequence of instructions. Performs an operation and returns a value.
Begins with Sub. Begins with Function.
Ends with End Sub. Ends with End Function.

Simple Function Example

Function AddTwoNumbers(a As Double, b As Double) As Double AddTwoNumbers = a + b End Function

Understanding the Example

  • AddTwoNumbers is the function name.
  • a and b are parameters.
  • The function adds the two values.
  • The result is returned through the function name.
If the function receives 10 and 20, the returned result will be 30.

11. Passing Arguments to a Macro or Function

Argument: A value supplied to a procedure or function when it is called.
Parameter: A variable in the procedure or function definition that receives the supplied value.

Why Are Arguments Used?

Arguments make a macro or function more flexible. Instead of writing a separate macro for every value, the same macro or function can receive different values.

Example

Sub WriteDouble(n As Double) Dim sheet As Object sheet = ThisComponent.Sheets.getByIndex(0) sheet.getCellRangeByName("B3").Value = n * 2 End Sub

Here, n is a parameter. A value can be supplied to the procedure when it is called from another piece of Basic code.

Using an Argument

Sub UseArgument WriteDouble 25 End Sub

In this example, 25 is supplied as an argument to the WriteDouble procedure.

Remember:
Parameter = variable receiving the value.
Argument = actual value supplied to it.

12. Working with Values

Macros and functions can work with values obtained from calculations, variables or spreadsheet cells.

Common Operations with Values

  • Reading a value.
  • Storing a value in a variable.
  • Performing calculations.
  • Changing a value.
  • Writing a value into a cell.
  • Returning a value from a function.

Example of Calculation

Dim total As Double total = 50 + 25

The variable total stores the result of the calculation.

Using Built-in Functions

LibreOffice Basic provides built-in functions that can be used for different operations.

Example:
result = Sqr(81)

The Sqr() function calculates the square root. In this example, the result is 9.

Built-in functions reduce the need to manually program common operations.

13. Direct Cell Access

Direct Cell Access:
Direct cell access means referring to a particular spreadsheet cell through macro instructions so that the macro can read or change its contents.
Simple Definition:
It means using a macro to directly read information from a cell or write information into a cell.

Cell Reference

A cell reference identifies the location of a cell. For example:

  • A1
  • B2
  • C5
  • D10

Accessing a Sheet

A macro can access a worksheet and then access a particular cell or cell range.

Reading a Cell Value

Dim sheet As Object Dim value As Double sheet = ThisComponent.Sheets.getByIndex(0) value = sheet.getCellRangeByName("B2").Value

The value stored in cell B2 is read and stored in the variable value.

Writing a Value into a Cell

sheet.getCellRangeByName("B3").Value = 100

This places the numerical value 100 into cell B3.

For numerical data, .Value is commonly used. Text can be handled using the cell's string content.

14. Practical: Macro for Cell Access and Calculation

We will create a simple macro that reads a number from one cell, multiplies it by 2 and places the result in another cell.

Step 1 – Open Calc

  1. Open LibreOffice Calc.
  2. Create a new spreadsheet.

Step 2 – Enter the Input

  1. Click cell B2.
  2. Enter a number, for example 25.
  3. Press Enter.

Step 3 – Open Basic Macro Editor

  1. Open Tools.
  2. Select Macros.
  3. Select Organize Macros.
  4. Select Basic.
  5. Select the required library.
  6. Select a module.
  7. Open the editor.

Step 4 – Create the Macro

Enter:

Sub ReadAndCalculate Dim sheet As Object Dim value As Double sheet = ThisComponent.Sheets.getByIndex(0) value = sheet.getCellRangeByName("B2").Value sheet.getCellRangeByName("B3").Value = value * 2 End Sub

Step 5 – Understand the Code

  • sheet represents the worksheet.
  • value stores the value read from B2.
  • B2 is the input cell.
  • B3 is the output cell.
  • value * 2 performs the calculation.
  • The result is written into B3.

Step 6 – Save the Macro

  1. Save the macro in the appropriate library and module.
  2. Give it a meaningful name.
  3. Save your work.

Step 7 – Run the Macro

  1. Return to the spreadsheet.
  2. Open the macro run option.
  3. Select ReadAndCalculate.
  4. Click Run.

Step 8 – Verify the Result

If B2 contains 25, the macro should place 50 in B3.

If the result does not appear, check the sheet index, cell references, macro name, saved location and whether the macro was executed successfully.

15. Sorting Columns Using a Macro

Definition:
Sorting means arranging data according to a selected field or column in a particular order, such as ascending or descending order.

A sorting operation can be recorded as a macro so that the same sorting procedure can be repeated.

Example

Name Marks
Ravi 65
Anita 92
Rahul 78

The data can be sorted according to the Marks column.

Practical Steps

  1. Open the spreadsheet.
  2. Enter the data.
  3. Include the column headings.
  4. Select the complete data range.
  5. Open the Data menu.
  6. Select Sort.
  7. Choose the column by which the data should be sorted.
  8. Choose ascending or descending order.
  9. Check that the correct range and heading settings are selected.
  10. Click OK.
  11. Check whether the data has been sorted correctly.
  12. If you are recording the operation, start macro recording before performing the sorting actions.
  13. Perform the sorting operation.
  14. Stop recording after completing the required actions.
  15. Save the macro with a meaningful name such as SortMarks.
  16. Run the macro on suitable test data.
  17. Verify the result.
A recorded sorting macro may depend on the worksheet structure or recorded range. Test it carefully before using it on different datasets.

16. Advantages of Using Macros

  • Saves time: Repeated operations can be performed quickly.
  • Reduces repetitive work: The user does not need to perform the same sequence manually each time.
  • Consistency: The same instructions can be repeated.
  • Automation: Several operations can be performed through one macro.
  • Useful for large tasks: Repeated operations on spreadsheet data can become easier.
  • Customisation: Programmed macros can be designed for particular tasks.

17. Limitations and Precautions

  • A macro may contain incorrect instructions.
  • A mistake in a macro can produce incorrect results.
  • Recorded macros may depend on the worksheet structure.
  • Macros should be tested before use on important data.
  • Keep a backup of important spreadsheets.
  • Use meaningful macro names.
  • Do not make unnecessary changes while recording.
  • Do not blindly enable macros from unknown or untrusted sources.
  • Save your work before testing a newly created macro.
Best Practice: First test a new macro on sample data. After confirming that it works correctly, use it on important data.

19. Macro vs Formula

Basis Formula Macro
Purpose Usually performs calculations. Automates a sequence of operations.
Location Usually entered in a cell. Stored as macro code.
Programming Uses spreadsheet formula syntax. Can use LibreOffice Basic.
Operations Mainly calculations and logical operations. Can automate multiple spreadsheet actions.
Example =SUM(A1:A5) A macro that formats and sorts data.

20. Recorded Macro vs Manually Created Macro

Recorded Macro Manually Created Macro
Created by recording supported user actions. Created by writing Basic instructions.
Useful for repetitive actions. Useful for customised or advanced operations.
Does not require writing every instruction manually. Requires understanding of programming instructions.
Can be quick to create. Can provide greater control over the operation.

21. Common Practical Mistakes

  1. Macro not saved: Always save the macro after creating or recording it.
  2. Wrong library or module: Remember where the macro is stored.
  3. Unclear macro name: Use meaningful names.
  4. Stopping recording too early: Make sure all required actions have been completed before stopping.
  5. Performing unnecessary actions: Only perform the actions that should be part of the macro.
  6. Wrong cell reference: Check the input and output cell references carefully.
  7. Wrong data: Test the macro using suitable sample data.
  8. Not checking the result: Always verify the output.
  9. Not saving the spreadsheet: Save your work before and after important changes.
  10. Using an untested macro: Test it before applying it to important data.

24. Application-Based Questions

Case 1 – Repeated Formatting

A teacher prepares a marks table every week. The heading must always be made bold, aligned and formatted in the same way.

View Answer

A macro can be recorded to automate the repeated formatting operations. The teacher can run the macro whenever the same formatting is required.

Case 2 – Reading and Calculating Cell Values

A student wants a macro to read a number from B2, multiply it by 2 and place the result in B3.

View Answer

The macro should directly access B2, store its value in a variable, multiply the value by 2 and write the result into B3.

Case 3 – Sorting Student Marks

A teacher repeatedly sorts student marks according to the Marks column.

View Answer

The sorting operation can be recorded as a macro. After testing, the macro can be run to repeat the sorting operation.

Case 4 – Function with Arguments

A programmer wants one function that can add different pairs of numbers instead of creating a separate function for every pair.

View Answer

The function can use parameters to receive the two numbers as arguments and return their sum.
