Basic ICT Skills-I

Class 9 — Information Technology (402)

1. Introduction to ICT

Definition 1: Information and Communication Technology (ICT) refers to the technologies, devices, software and communication systems used to create, collect, process, store, retrieve and exchange information.
Definition 2: ICT is a combination of computing and communication technologies that enables people to access information, process data and communicate with others through digital systems.

In Simple Words

ICT means using computers, mobile devices, networks, the Internet and other digital technologies to handle information and communicate with people.

Examples of ICT

  • Computers and laptops
  • Smartphones and tablets
  • Internet
  • Email
  • Video conferencing
  • Websites
  • Digital cameras
  • Printers and scanners
  • Cloud services

2. Components of ICT

ICT systems work through several components that work together to collect, process, store and communicate information.

1. Hardware

Hardware refers to the physical parts of a computer or ICT system that can be seen and touched.

Examples include keyboard, mouse, monitor, CPU, printer, scanner and storage devices.

2. Software

Software is a collection of programs and instructions that tells computer hardware what to do.

Examples include operating systems, word processors, web browsers and presentation software.

3. Data

Data refers to raw facts and figures that can be entered into a computer for processing.

4. Information

Information is meaningful and useful data obtained after processing and interpretation.

5. Communication Network

A communication network connects computers and other devices so that data and resources can be shared.

6. Users

Users are people who operate ICT devices and use ICT services to perform different tasks.

3. ICT Devices

ICT devices are electronic devices used for entering, processing, storing, displaying or communicating information.

  • Desktop computer
  • Laptop
  • Tablet
  • Smartphone
  • Keyboard
  • Mouse
  • Monitor
  • Printer
  • Scanner
  • Projector
  • Digital camera
  • Storage devices
  • Networking devices

4. Basic Computer Operations

Basic computer operations are the fundamental skills required to start, operate, manage, customise and properly shut down a computer.

4.1 Starting a Computer

Definition: Starting a computer means switching on the computer system and allowing the operating system to load so that the user can perform different tasks.

Steps to Start a Computer

  1. Make sure the computer is properly connected to a power source.
  2. Switch on the main power supply if required.
  3. Switch on the UPS, if available.
  4. Press the Power button on the computer or laptop.
  5. Switch on the monitor if it has a separate power button.
  6. Wait while the computer starts.
  7. Allow the operating system to load.
  8. The login screen or desktop will appear.
  9. Enter the password or PIN if required.
  10. The computer is now ready for use.
Important: Do not repeatedly press the Power button while the computer is starting.

4.2 Desktop

Definition: The desktop is the main working area displayed by the operating system after the computer starts. It provides access to files, folders, applications and system features.

Main Elements of a Desktop

  • Icons
  • Start menu
  • Taskbar
  • Notification area
  • Search
  • Background or wallpaper
  • Recycle Bin

5. Using the Mouse

Definition 1: A mouse is a pointing input device used to control the pointer on a computer screen and interact with graphical objects.
Definition 2: A mouse allows the user to select, open, move and manipulate items displayed on the computer screen.

Basic Mouse Actions

1. Point

Move the mouse pointer over an object on the screen.

2. Click

Press and release the left mouse button once. It is commonly used to select an item or activate a button.

3. Double-click

Press the left mouse button twice quickly. It is commonly used to open files, folders or applications.

4. Right-click

Press the right mouse button once. It normally opens a context menu containing relevant commands.

5. Drag and Drop

Press and hold the mouse button, move the pointer to another location and release the button. It can be used to move objects, files or folders.

6. Scroll

Use the mouse wheel to move up or down through a document, webpage or other content.

6. Introduction to Keyboard

Definition 1: A keyboard is an input device containing keys that allow users to enter text, numbers, symbols and commands into a computer.
Definition 2: The keyboard is one of the most commonly used input devices for communicating instructions and entering information into a computer system.

Types / Groups of Keyboard Keys

Type of Key Examples Main Use
Alphabet Keys A–Z Entering letters and words
Number Keys 0–9 Entering numbers
Function Keys F1–F12 Performing different functions depending on software
Control / Modifier Keys Ctrl, Alt, Shift, Windows Commands and keyboard shortcuts
Navigation Keys Arrow, Home, End, Page Up, Page Down Moving and navigating
Editing Keys Delete, Backspace, Insert Editing content
Special Keys Enter, Esc, Tab, Spacebar Special commands and input
Toggle Keys Caps Lock, Num Lock, Scroll Lock Switching a function on or off

Important Keyboard Keys

  • Enter: Confirms commands or moves to a new line in many applications.
  • Spacebar: Inserts a space between words.
  • Backspace: Deletes the character to the left of the cursor.
  • Delete: Deletes selected items or characters depending on the context.
  • Shift: Used for capital letters and upper characters.
  • Caps Lock: Toggles continuous uppercase typing.
  • Tab: Moves to the next tab position or field.
  • Esc: Commonly cancels or exits an operation or menu.
  • Ctrl: Used with other keys for shortcuts.
  • Alt: Used with other keys for commands and shortcuts.

7. Basic File and Folder Operations

File: A file is a collection of digitally stored information identified by a name.
Folder: A folder is a container used to organise files and other folders in a computer system.

Basic Operations

  • Create: Make a new file or folder.
  • Open: Access a file or folder.
  • Save: Store changes made to a file.
  • Save As: Save a file with a different name, location or format.
  • Copy: Create another copy while keeping the original.
  • Cut: Prepare an item to be moved.
  • Paste: Place copied or cut content at another location.
  • Rename: Change the name of a file or folder.
  • Move: Change the location of a file or folder.
  • Delete: Remove a file or folder from its current location.
  • Restore: Recover a deleted item from the Recycle Bin when available.
  • Search: Find files or folders using available search options.

File Extensions

A file extension is the part of a filename that usually indicates the file type or format.

Extension File Type
.txtText file
.docxWord document
.pdfPDF document
.pptxPresentation
.xlsxSpreadsheet
.jpg / .jpegImage
.pngImage

8. Recycle Bin

Definition: The Recycle Bin is a system location where deleted files and folders are usually stored temporarily before they are permanently deleted.

Common Operations

  • Restore an item
  • Delete an item permanently
  • Empty the Recycle Bin

9. Basic Desktop Customisation

Definition: Desktop customisation means changing the appearance and selected settings of the desktop according to the user's preferences.

Common Customisation Options

  • Change wallpaper/background
  • Change theme
  • Change display settings
  • Adjust display scaling where available
  • Arrange desktop icons
  • Change taskbar settings
  • Set screen saver where supported
  • Adjust date and time settings

Changing Desktop Background

  1. Right-click an empty area of the desktop.
  2. Select the appropriate Personalise/Personalization option.
  3. Open the background settings.
  4. Select a picture, colour or available background option.
  5. Apply or save the changes.

Arranging Desktop Icons

Desktop icons can generally be moved, arranged and sorted. Depending on the operating system, icons may be arranged automatically or sorted by name, size, type and other options.

10. Control Panel and Basic Settings

Definition 1: Control Panel is a Windows system configuration interface that provides access to various settings used to manage a computer.
Definition 2: Control Panel contains tools for managing hardware, software, user accounts, network settings, accessibility and other system-related features.

Common Uses of Control Panel

  • Managing user accounts
  • Uninstalling programs
  • Managing devices and printers
  • Changing date and time
  • Managing network settings
  • Adjusting mouse settings
  • Adjusting keyboard settings
  • Managing accessibility options
  • Managing power options
  • Changing system-related settings

Basic Mouse Settings

Mouse settings may allow users to adjust button configuration, double-click speed, pointer options, pointer appearance and scrolling behaviour.

Basic Keyboard Settings

Keyboard-related settings may include keyboard repeat rate, cursor blink rate, language/input settings and accessibility features.

Basic Display Settings

Display settings may include screen resolution, display scaling, orientation and multiple-display configuration.

Date and Time Settings

Correct date and time settings are important for file timestamps, scheduling, online services and normal system operations.

User Accounts

A user account identifies a person using a computer and can provide separate settings, files and permissions.

  • Username
  • Password/PIN
  • Administrator privileges
  • Standard user

Installing and Uninstalling Programs

Software applications can be installed when needed. Uninstalling means removing a program from the computer using the operating system's appropriate uninstall mechanism.

Important: Simply deleting a program's shortcut does not normally uninstall the program itself.

11. Shutting Down a Computer

Definition: Shutting down means properly closing the operating system and turning off the computer so that running processes are ended safely.

Steps to Shut Down

  1. Save your work.
  2. Close open applications.
  3. Open the Start menu.
  4. Select the Power option.
  5. Select Shut down.
  6. Wait for the computer to turn off completely.
  7. Switch off external power supply if required.
Important: Do not normally switch off the computer directly from the main power supply while it is running.

12. Basic Internet and Web Concepts

Internet

The Internet is a global network of interconnected computer networks that allows devices to communicate and exchange information.

World Wide Web

The World Wide Web (WWW) is a system of interlinked web resources that users access through the Internet using web browsers.

Website

A website is a collection of related webpages and other resources available under a common web address.

Webpage

A webpage is an individual page or resource displayed through a web browser.

URL

URL stands for Uniform Resource Locator. It is the address used to locate a resource on the Web.

Example: https://www.example.com

Web Browser

A web browser is software used to access and display webpages.

Examples include Google Chrome, Mozilla Firefox, Microsoft Edge, Safari and Opera.

Search Engine

A search engine is an online service that helps users find information on the Web using keywords or search queries.

Examples include Google, Bing and DuckDuckGo.

Remember: A browser and a search engine are not the same thing.

13. Email and Digital Communication

Email: Email, or Electronic Mail, is a digital communication method used to send and receive messages and files over computer networks and the Internet.

Important Email Fields

  • To: Main recipient
  • Cc: Additional visible recipients
  • Bcc: Additional recipients whose addresses are hidden from other recipients
  • Subject: Brief description of the message
  • Message: Main content of the email
  • Attachment: File sent with the email

Other Digital Communication Methods

  • Instant messaging
  • Video conferencing
  • Online collaboration
  • Discussion forums
  • Educational platforms

14. Digital Safety and Responsible Use of ICT

Cyber Safety

Definition: Cyber safety means taking appropriate precautions to protect yourself, your data, accounts and devices while using digital technologies and online services.

Important Safety Practices

  • Use strong and unique passwords.
  • Do not share passwords with others.
  • Be careful with unknown links and attachments.
  • Keep software updated.
  • Use trusted sources for downloads.
  • Protect personal information.
  • Use appropriate privacy settings.
  • Verify information before sharing it.

Phishing

Phishing is a fraudulent attempt to obtain sensitive information by pretending to be a trustworthy person, organisation or service.

Malware

Malware means malicious software designed to disrupt, damage, misuse or gain unauthorised access to computer systems or data.

Digital Footprint

Definition: A digital footprint is the record or trail of information and activities that a person leaves while using digital devices and online services.

Digital Citizenship

Definition: Digital citizenship means using digital technology in a safe, responsible, respectful, ethical and informed manner.

A Responsible Digital Citizen

  • Respects others online.
  • Protects privacy.
  • Follows rules and laws.
  • Avoids cyberbullying.
  • Checks information before sharing.
  • Respects intellectual property.
  • Uses technology constructively.

15. Applications of ICT

ICT in Education

  • Digital notes
  • Presentations
  • Educational videos
  • Online classes
  • Digital assessments
  • Research
  • Collaborative learning

ICT in Banking

ICT supports ATMs, online banking, digital payments, electronic records and other banking services.

ICT in Healthcare

ICT supports digital records, appointments, communication, medical information systems and telemedicine.

ICT in Business

Businesses use ICT for accounting, communication, data management, customer service, marketing and automation.

ICT in Government

Government organisations use ICT for digital records, online applications, public services and communication.

ICT in Communication

Email, messaging, social communication platforms and video conferencing allow people to communicate quickly over distance.

16. Advantages and Limitations of ICT

Advantages

  • Fast communication
  • Easy access to information
  • Saves time
  • Improves productivity
  • Easy storage and retrieval of information
  • Supports collaboration
  • Supports education and learning
  • Helps automate routine tasks

Limitations

  • Security risks
  • Privacy concerns
  • Digital divide
  • Dependence on technology
  • Misinformation
  • Possible misuse
  • Need for digital skills
