UNIT 1: DIGITAL DOCUMENTATION (ADVANCED)

Class 10 Information Technology – Code 402

📘 About This Unit

Digital Documentation (Advanced) focuses on creating, formatting and managing professional documents using LibreOffice Writer. In this unit, students learn advanced features that make document creation easier, more organised and more professional.

The unit is divided into five sessions. Each session covers a specific topic with concepts, definitions, practical procedures, important questions and application-based learning.
