Session 4 – Share and Review Spreadsheet

Electronic Spreadsheet (Advanced) – LibreOffice Calc

1. Introduction to Sharing and Reviewing a Spreadsheet

A spreadsheet is often prepared and maintained by more than one person. For example, teachers, office staff, accountants, or members of a project team may need to work with the same spreadsheet.

LibreOffice Calc provides features that help users share spreadsheet information, record changes, add comments, review modifications, merge changes, and compare different versions of a spreadsheet.

Definition – Spreadsheet Sharing:
Spreadsheet sharing is the process of allowing multiple users to work with the same spreadsheet document so that information can be maintained and updated collaboratively.
In simple words:
Sharing a spreadsheet means allowing different people to work on the same spreadsheet and manage their changes properly.
Example:
Suppose a school maintains a spreadsheet containing student attendance. The class teacher may enter attendance while another staff member checks or updates related information.

2. Sharing a Spreadsheet

Definition:
Sharing a spreadsheet is a feature that allows a spreadsheet document to be used by multiple users for collaborative work.
Simple Definition:
It allows more than one person to work with a spreadsheet document.

Why is Spreadsheet Sharing Useful?

  • It supports collaborative work.
  • Multiple users can work with the same spreadsheet.
  • It reduces the need to maintain many separate copies.
  • It helps teams manage common data.
  • It can make office and school work more organised.

Enabling Spreadsheet Sharing

In LibreOffice Calc, spreadsheet sharing can be enabled through the Tools menu.

  1. Open the spreadsheet in LibreOffice Calc.
  2. Click the Tools menu.
  3. Look for the spreadsheet sharing option.
  4. Enable the sharing feature.
  5. Save the spreadsheet.
Tip:
Before sharing a spreadsheet, make sure that the file is saved properly and that the users understand which data they are expected to modify.
Precaution:
When multiple users work with the same spreadsheet, changes should be managed carefully to avoid confusion or conflicting versions.

3. Opening a Shared Spreadsheet

Definition:
Opening a shared spreadsheet means accessing a spreadsheet document that has been configured for collaborative use.

Steps to Open a Shared Spreadsheet

  1. Start LibreOffice Calc.
  2. Open the shared spreadsheet file.
  3. Check whether the document is configured for sharing.
  4. Review the existing spreadsheet data.
  5. Make only the required changes.
  6. Save the document after completing the work.
Good Practice:
Always check the current data before making changes. This reduces the chance of accidentally changing information entered by another user.

4. Saving a Shared Spreadsheet

Saving is particularly important when a spreadsheet is being used by multiple people. Users should save their changes carefully so that the latest information is maintained.

Steps

  1. Complete the required changes.
  2. Check the modified cells.
  3. Click File → Save.
  4. Wait for the document to finish saving.
  5. Check the spreadsheet again if required.
Important:
When several users modify a shared spreadsheet, conflicts or differences may occur. Therefore, users should communicate with one another and review changes carefully.

5. Recording Changes

Definition:
Recording changes is the process of keeping track of modifications made to a spreadsheet so that the changes can later be reviewed.
In simple words:
It keeps a record of what has been changed in the spreadsheet.

Why Record Changes?

  • It helps identify modifications.
  • It helps review the work of different users.
  • It makes checking changes easier.
  • It can help identify unwanted modifications.
  • It supports collaborative spreadsheet work.

General Steps for Recording Changes

  1. Open the spreadsheet in LibreOffice Calc.
  2. Open the menu related to tracking or recording changes.
  3. Enable the option for recording changes.
  4. Modify the required cells.
  5. Save the spreadsheet.
  6. Review the recorded changes later.
Example:
If the original sales value is ₹50,000 and a user changes it to ₹55,000, recording changes helps identify that the value was modified.

6. Comments in a Spreadsheet

Definition:
A comment is an explanatory note attached to a cell to provide additional information, clarification, or instructions about the cell's content.
Simple Definition:
A comment is a small note added to a cell to explain something about it.

Purpose of Comments

  • To explain a value.
  • To provide instructions.
  • To ask another user to check something.
  • To provide additional information.
  • To clarify unusual or important data.

Adding a Comment

  1. Select the required cell.
  2. Use the appropriate comment option from the menu or context menu.
  3. Enter the required text.
  4. Save the document.
Example:
A teacher may add a comment to a marks cell saying that the marks need to be verified from the original record.

Editing a Comment

  1. Select the cell containing the comment.
  2. Open the comment.
  3. Edit the required text.
  4. Save the spreadsheet.

Deleting a Comment

  1. Select the cell containing the comment.
  2. Open the comment options.
  3. Choose the option to delete the comment.
Remember:
A comment explains information. It is different from a recorded change, which identifies a modification made to the spreadsheet.

7. Reviewing Changes

Definition:
Reviewing changes is the process of examining modifications made to a spreadsheet and deciding whether those changes should be accepted or rejected.
In simple words:
Reviewing changes means checking what someone changed and deciding whether to keep the change or remove it.

Accepting and Rejecting Changes

After changes have been recorded, they can be reviewed. A user may accept a suitable change or reject a change that is incorrect or unwanted.

General Steps

  1. Open the spreadsheet containing recorded changes.
  2. Open the change-review facility.
  3. Examine the listed changes.
  4. Select a change to review.
  5. Check whether the modification is correct.
  6. Accept the change if it is required.
  7. Reject the change if it is not required.
  8. Continue reviewing the remaining changes.
  9. Save the spreadsheet.
Precaution:
Do not accept or reject changes without checking the original information and the purpose of the modification.

8. Merging Changes

Definition:
Merging changes is the process of combining changes from different spreadsheet versions into a single spreadsheet document.
Simple Definition:
Merging means bringing changes from different copies together into one spreadsheet.

Why is Merging Required?

  • Different users may work on separate copies.
  • Each copy may contain useful changes.
  • The changes may need to be combined.
  • It helps create a consolidated version of the document.

General Process

  1. Keep the original spreadsheet and modified copies available.
  2. Open the spreadsheet that will contain the merged information.
  3. Use the appropriate merge-changes feature.
  4. Select the spreadsheet containing the other changes.
  5. Allow Calc to process the changes.
  6. Review any conflicts or differences.
  7. Save the final spreadsheet.
Important:
Always review merged information. Automatically combining changes does not mean that every change is necessarily correct.

9. Comparing Spreadsheets

Definition:
Comparing spreadsheets is the process of examining two spreadsheet documents or versions to identify differences between them.
In simple words:
Comparison helps us find out what is different between two spreadsheet versions.

Why Compare Spreadsheets?

  • To identify changed values.
  • To find differences between versions.
  • To check whether information was modified.
  • To verify updated records.
  • To help review documents.

General Steps

  1. Open the spreadsheet that you want to use for comparison.
  2. Use the spreadsheet comparison feature.
  3. Select the other spreadsheet version.
  4. Allow Calc to compare the documents.
  5. Examine the identified differences.
  6. Verify the differences with the original information.
Example:
A school has an attendance spreadsheet from Monday and another version updated on Tuesday. Comparing the two versions can help identify which attendance entries were modified.

10. Practical: Add and Manage Comments

Activity

Create a small student-marks spreadsheet and add comments to selected cells.

Step-by-Step Procedure

  1. Open LibreOffice Calc.
  2. Create a new spreadsheet.
  3. Enter headings such as: Name, English, Mathematics, Science.
  4. Enter marks for a few students.
  5. Select the cell that requires an explanation.
  6. Open the comment option.
  7. Enter a suitable comment.
  8. Save the spreadsheet.
  9. Select another cell and add another comment if required.
  10. Edit a comment to practise modification.
  11. Delete a comment that is no longer required.
  12. Save the final spreadsheet.
Practice Example:
Add a comment to a student's Mathematics marks explaining: "The marks should be verified from the original record."

11. Practical: Record and Review Changes

Activity

Create a spreadsheet, enable change recording, modify some data, and then review the modifications.

Step-by-Step Procedure

  1. Open LibreOffice Calc.
  2. Create a small table containing student names and marks.
  3. Save the spreadsheet.
  4. Enable the option for recording changes.
  5. Change one or more values.
  6. Add another entry if required.
  7. Save the spreadsheet.
  8. Open the facility for reviewing recorded changes.
  9. Examine the changes one by one.
  10. Accept a correct change.
  11. Reject an incorrect or unwanted change.
  12. Save the spreadsheet after reviewing the changes.

12. Practical: Compare Spreadsheet Versions

Activity

Create two versions of a spreadsheet and compare them to identify differences.

Step-by-Step Procedure

  1. Create a spreadsheet containing some sample data.
  2. Save the first version of the spreadsheet.
  3. Make a copy or create another version of the file.
  4. Modify some values in the second version.
  5. Save the modified version separately.
  6. Open the spreadsheet that you want to use for comparison.
  7. Use the spreadsheet comparison feature.
  8. Select the other spreadsheet version.
  9. Examine the differences identified by Calc.
  10. Verify whether the differences are correct.

13. Share vs Record Changes vs Compare

Feature Purpose Simple Meaning
Share Spreadsheet Allows collaborative use of a spreadsheet. More than one user can work with the spreadsheet.
Record Changes Keeps track of modifications. Shows what was changed.
Comments Adds explanatory information to cells. Adds a note to a cell.
Review Changes Checks recorded modifications. Decides whether changes should be kept.
Merge Changes Combines changes from different versions. Brings changes together.
Compare Spreadsheets Identifies differences between versions. Finds what is different.

14. Common Practical Mistakes

  • Not enabling sharing: Users may assume that a spreadsheet is shared when it is not.
  • Not recording changes: Modifications may become difficult to identify later.
  • Using the wrong file: Always verify the spreadsheet version before editing.
  • Confusing comments with tracked changes: A comment is an explanatory note, while a recorded change represents a modification to spreadsheet content.
  • Accepting changes without checking: Every important change should be reviewed before acceptance.
  • Rejecting changes without verification: A useful modification may be lost if it is rejected without checking.
  • Not reviewing merged data: Merged information should always be checked.
  • Not saving the final document: Always save after completing important changes.
